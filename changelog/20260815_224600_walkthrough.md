## 🐛 Bugs Đã Fix

### Bug 1 (Nghiêm trọng) — `export.js`: setInterval không dừng khi tab downloader bị đóng sớm
- **Vấn đề:** `setInterval` gọi `helperWindow.postMessage(...)` mỗi 250ms trong 7.5 giây. Nếu user đóng tab trước khi hết, gây uncaught error liên tục.
- **Fix:** Thêm guard `if (!helperWindow || helperWindow.closed) { clearInterval; return; }` trong mỗi tick. Thêm `clearInterval` trong catch block.

### Bug 2 (Nghiêm trọng) — `formatters.js`: parseNumericValue sai với số âm có dấu chấm ngàn
- **Vấn đề:** Điều kiện `!parts[0].includes('-')` khiến `-1.500`, `-10.000` bị parse là decimal thay vì số ngàn.
- **Fix:** Dùng `intPart = parts[0].replace('-', '')` rồi check `intPart.length <= 3`.

### Bug 3 (Trung bình) — `rules.js`: `evaluateConditionalRule` dùng `Number(val)` không nhất quán
- **Vấn đề:** `Number("1,500")` trả NaN → conditional rule không trigger với số định dạng phẩy ngàn.
- **Fix:** Đổi thành `parseNumericValue(val, fieldType)`.

### Bug 4 (Trung bình) — `summary.js`: maxDecimalPlaces bị floating-point error
- **Vấn đề:** `String(num)` sau tích lũy JS có thể cho `0.30000000000000004` → maxDecimalPlaces bị phồng.
- **Fix:** Tính từ raw value string gốc: `String(val).trim().replace(/,/g, '')`.
