# Walkthrough v3.19 — 2026-08-15 18:17

## Tóm tắt
Thêm tính năng cấu hình per-column aggregation động qua TEXTINPUT trong Looker Studio Style panel.
Cũng fix decimal detection dùng String(num) thay vì parse lại chuỗi.

## Các thay đổi

### index.json
- summaryType label đổi thành "Phép tính mặc định (fallback nếu không cấu hình từng cột)"
- Thêm field mới: perColumnSummary TEXTINPUT, placeholder "m1:sum, m2:avg, m3:min..."
- defaultValue: "" (rỗng = không override, dùng summaryType fallback)

### src/index.js

#### Parse perColumnSummary (dòng ~1033-1051)
- Đọc styleConfig.perColumnSummary.value
- Split theo dấu phẩy, match regex /^m\s*(\d+)\s*:\s*(sum|avg|min|max|count)$/i
- Build metricAggOverrides = { 0: 'sum', 1: 'avg', 2: 'min' } (0-based index)
- Flexible: chấp nhận "M2:AVG", "m 3 : min" (case-insensitive, space-tolerant)

#### Summary calculation loop (dòng ~1164-1180)
- Thêm metricPosition counter (m1=0, m2=1, m3=2, ...)
- Priority resolution: metricAggOverrides[pos] > col.fieldSummaryType > summaryType
- metricPosition++ sau mỗi metric column

#### Decimal detection fix (dòng ~1187-1197)
- Thay complex string-based detection bằng String(num)
- String(18123.456) = "18123.456" → detect 3 decimals đúng
- Không bị false-negative với .456 (3 digits) nữa

## Hướng dẫn sử dụng trong Looker Studio
1. Chọn chart → Style tab → tìm "Phép tính từng Metric"
2. Gõ: m1:sum,m2:avg,m3:min (m1 = metric đầu tiên trong Setup)
3. Lưu báo cáo → dòng Tổng cộng tự động dùng đúng aggregation cho từng cột
