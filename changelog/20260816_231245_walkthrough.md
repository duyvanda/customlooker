## 🎯 Nội Dung Triển Khai & Hoàn Tất

1. **Khôi Phục Subscriber Chuẩn Gốc (Loại bỏ 3 tầng watchdog):**
   - Loại bỏ toàn bộ các tầng watchdog/resubscribe/reload gây xung đột trên Looker Studio.
   - Sử dụng trực tiếp `dscc.subscribeToData(drawVisualization, { transform: dscc.tableTransform })`.
   - Giữ nguyên cơ chế tự động giải phóng bộ nhớ cache khi nhận dataset mới.

2. **Toàn Bộ Các Tối Ưu Hiệu Năng & Bộ Nhớ (RAM):**
   - Cache kết quả Filter + Sort (`processedRowsCache`), phân trang $O(1)$.
   - Cache kết quả Dòng Tổng Hợp (`summaryCache`).
   - Debounce 250ms cho ô Search, phím Enter thực thi tức thì.
   - Chặn và giới hạn an toàn phân trang `"Tất cả"` khi dữ liệu $> 5.000$ dòng.
   - Bỏ duplicate `excelDataObjects`, chuyển export sang async và `yieldToBrowser()` mỗi 5.000 dòng.
   - Tính toán `excelColumnWidths` trực tiếp trong vòng lặp xuất file.

3. **Xuất File An Toàn & Chuẩn Bảo Mật:**
   - Giao thức Handshake 2 chiều (`DOWNLOADER_PING` $\rightarrow$ `DOWNLOADER_PONG`), gửi payload **đúng 1 lần duy nhất**.
   - SheetJS `xlsx-0.20.3` chính thức.
   - Xuất Excel với Dense Worksheet (`aoa_to_sheet` + `{ dense: true }`).
   - Xuất CSV theo Chunking 5.000 dòng nạp vào `Blob`.
   - Chống **CSV / Formula Injection** trong `escapeCsvCell`.
   - Tự động **giải phóng RAM** (`globalData.rows = null`) sau khi tải xong Dataset $> 200\text{k}$ dòng.

4. **Dọn Dẹp Repository & Archive:**
   - Đã dọn sạch toàn bộ các file version cũ trong thư mục [archive/](file:///D:/customLooker/archive).
   - Đóng gói [customLooker.zip](file:///D:/customLooker/customLooker.zip) siêu nhẹ (**93 KB**).
