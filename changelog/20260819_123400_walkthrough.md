## 🔍 Các vấn đề đã xử lý

### 1. Tôn trọng Datatype TEXT từ Looker Studio (Fix lỗi cắt chuỗi khi có ngày ở đầu text)
- **Hiện tượng cũ:** Khi một cột Text chứa chuỗi dạng `2026-08-02 | Sai đơn hàng...`, hàm `isDateValue` nhận diện nhầm thành Date, dẫn đến việc `formatTableCell` format thành `02-08-2026` và vô tình cắt mất phần text phía sau.
- **Xử lý:** Kiểm tra `if (ft === 'TEXT' || ft === 'STRING') return false;` trong `isDateValue` để tôn trọng 100% kiểu dữ liệu do Looker Studio cung cấp, không can thiệp format ngày vào cột Text.

### 2. Chuẩn hóa bộ Parse cấu hình sang Strict JSON `parseJsonConfig` & Fix lỗi `%H:%M:%S`
- **Hiện tượng cũ:** Khi người dùng nhập định dạng ngày giờ có giờ phút giây như `ngay tao don:%d-%m-%Y %H:%M:%S`, code cũ dùng `lastIndexOf(':')` bị bắt nhầm dấu `:` giữa `%M` và `%S`, khiến tên cột bị hiểu nhầm thành `ngay tao don:%d-%m-%Y %H:%M` và pattern bị cắt còn `%S`.
- **Xử lý:**
  - Viết hàm chuẩn `parseJsonConfig(rawString)` trong `src/formatters.js` sử dụng `JSON.parse` để parse cấu hình theo chuẩn JSON `{"key":"value"}`.
  - Tự động bao bọc `{ }` nếu người dùng nhập rút gọn `"key":"val", "key2":"val2"`.
  - Tự động chuẩn hóa key (chữ thường và bỏ dấu tiếng Việt).
  - Tích hợp vào 3 ô cấu hình trong `src/index.js`: `perColumnSummary`, `perColumnDateFormat`, `perColumnNumberFormat`.
  - Cập nhật nhãn ví dụ trong `index.json` và `index.v3.43.json` theo đúng định dạng `{"key":"value"}`.

1. **Cấu hình phiên bản:**
   - `webpack.config.js`: `output.filename = 'index.bundle.v3.43.js'`.
   - `manifest.json`: Trỏ tới `index.bundle.v3.43.js`, `index.v3.43.css`, `index.v3.43.json`.
2. **Đồng bộ asset:** Đã đồng bộ `src/index.css` -> `index.v3.43.css` và `index.json` -> `index.v3.43.json`.
3. **Build Webpack:** Biên dịch bundle `index.bundle.v3.43.js` thành công (55.9 KiB).
4. **Dọn dẹp:** Đã chuyển các file version cũ (`v3.42`) vào thư mục `archive/`.
5. **Đóng gói ZIP:** Tạo file `customLooker.zip` lưu trữ source code và assets mới.
6. **Deploy GCS:** Đã deploy thành công 6 files lên bucket `gs://analytics_merap/excelchart3/` với cờ `Cache-Control:no-cache, no-store, must-revalidate`.
