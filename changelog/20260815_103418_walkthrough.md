## 2. 🛠️ Chi Tiết Các Thay Đổi
- **[`manifest.json`](file:///D:/customLooker/manifest.json):**
  - Đổi tên thành **`Custom Table with Excel & CSV Export v3`**, tổ chức **`Duy Quang Data Solution v3`**, component **`Excel & CSV Export Table v3`** để dễ nhận biết phiên bản 3 trên Looker Studio.
  - Cập nhật tài nguyên trỏ sang `gs://analytics_merap/excelchart3/`.
- **[`src/index.js`](file:///D:/customLooker/src/index.js):**
  - Bổ sung khai báo `const tableColumns = extractTableColumns(currentData);` ở đầu hàm `renderTable()`.
  - Cache `VI_COLLATOR` một lần duy nhất ở đầu file (`const VI_COLLATOR = new Intl.Collator('vi', ...)`), loại bỏ overhead khi sort dataset lớn.
  - Bổ sung nút bấm **Xuất CSV** trên toolbar cạnh nút Xuất Excel.
  - Cập nhật logic nút Xuất Excel:
    - Nếu tổng số dòng **<= 200.000 dòng**: Nút màu xanh lá tiêu chuẩn với text **`Xuất Excel (<200k dòng)`**.
    - Nếu tổng số dòng **> 200.000 dòng**: Tự động chuyển nút sang **Màu Đỏ (`btn-excel-danger`)** với text **`Xuất Excel (>200k dòng)`** và tooltip cảnh báo để người dùng ưu tiên bấm Xuất CSV tránh crash trình duyệt.
  - Đọc và áp dụng tùy chọn độ rộng cột tối đa `--col-max-width` (mặc định `300px`) lên bảng.
  - Thêm cấu hình `showExcelExport`, `showCsvExport`, `colMaxWidth` vào Style config.
- **[`downloader.html`](file:///D:/customLooker/downloader.html):**
  - Tăng kích thước toàn bộ thẻ card (từ `640px` lên `820px`), tăng padding và độ nổi khối.
  - Tăng cỡ chữ toàn diện: Tiêu đề `24px` (đậm), phụ đề `15.5px`, mẹo F12 `15px`, nút bấm `15.5px` (padding `13px 22px`), số dòng dữ liệu `24px`.
  - Bổ sung hàm `downloadCsvFile()` xử lý xuất file CSV chuẩn.
  - Hiển thị cả 2 nút tải lại (CSV & Excel), nếu dataset > 200k dòng thì nút Excel hiển thị cảnh báo đỏ **`⚠️ Tải Lại Excel (>200k dòng - Dễ lag)`**.
  - Bổ sung khung thông báo nổi bật ngay từ đầu khi mở tab: **`💡 Mẹo chuyển sang Excel: Sau khi mở file CSV bằng Microsoft Excel ➔ Nhấn phím F12 (Save As) ➔ Chọn định dạng Excel Workbook (*.xlsx) để lưu lại thành file Excel chuẩn.`**
  - Sử dụng trick công thức `="0123"` (Excel text formula) đối với các chuỗi bắt đầu bằng số `0` (SĐT, mã định danh, text) để bảo toàn 100% số `0` ở đầu khi mở bằng Microsoft Excel.
  - Bổ sung tiền tố UTF-8 BOM (`\uFEFF`) để Excel hiển thị tiếng Việt có dấu chuẩn xác 100% không bị lỗi font.
- **[`index.css`](file:///D:/customLooker/index.css):**
  - Thêm styling hiện đại cho nút `.btn-csv` (gradient xanh lam) và `.btn-excel-danger` (gradient đỏ nổi bật khi >200k dòng).
  - Áp dụng `max-width: var(--col-max-width, 300px);` và `overflow: hidden; text-overflow: ellipsis;` cho cell khi không bật text wrap.
- **[`index.json`](file:///D:/customLooker/index.json):**
  - Thêm tùy chọn `colMaxWidth` (Độ rộng cột tối đa: 150px, 200px, 250px, 300px mặc định, 400px, 500px, Không giới hạn) trong tab Style (Giao diện Bảng).
  - Thêm 2 tùy chọn checkbox `showExcelExport` và `showCsvExport`.
- **[`src/index.js`](file:///D:/customLooker/src/index.js):** Đổi text nút Excel thành **`Xuất Excel (<200k)`** và **`Xuất Excel (>200k)`**.
- **[`webpack.config.js`](file:///D:/customLooker/webpack.config.js):** Cập nhật output bundle thành **`index.bundle.v3.1.js`**.
- **[`index.v3.1.css`](file:///D:/customLooker/index.v3.1.css):** Tạo bản CSS versioned `index.v3.1.css` có đầy đủ style `.btn-csv` và `.btn-csv svg`.
- **[`manifest.json`](file:///D:/customLooker/manifest.json):** Trỏ JS sang `index.bundle.v3.1.js`, CSS sang `index.v3.1.css`, và bật **`"devMode": false`** (Production CDN).
