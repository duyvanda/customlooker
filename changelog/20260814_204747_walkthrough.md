# Walkthrough: Custom Looker Studio Table Viz - Dedicated Technical Documentation Separation

## 1. Tóm tắt các thay đổi vừa hoàn thiện

1. **Tách tài liệu Phân tích Kỹ thuật thành file độc lập:**
   - Đã tạo file riêng biệt: [`EXPORT_SANDBOX_AND_WEBVIEW_ANALYSIS.md`](file:///D:/customLooker/EXPORT_SANDBOX_AND_WEBVIEW_ANALYSIS.md) ghi chép toàn diện về:
     - Cơ chế bảo mật Sandbox Iframe của Looker Studio & nguyên nhân lỗi `allow-downloads`.
     - Kiến trúc giải pháp Helper Tab ([`downloader.html`](file:///D:/customLooker/downloader.html)).
     - Phân tích nguyên nhân ngắt kết nối `postMessage` trên Android In-App WebView.
     - Các giải pháp cho người dùng cuối (Chrome/Safari di động) và cấu hình `WebChromeClient` cho Mobile App Developers.
   - Giữ file [`agent.md`](file:///D:/customLooker/agent.md) ngắn gọn, tập trung chuẩn vào quy tắc vận hành, kiến trúc Setup/Style và quy trình build/deploy.
2. **Cập nhật gói ZIP & Triển khai:**
   - Cập nhật gói [`customLooker.zip`](file:///D:/customLooker/customLooker.zip).
   - Deploy GCS `gs://analytics_merap/excelchart2/`.
   - Push commit mới lên GitHub: [https://github.com/duyvanda/customlooker.git](https://github.com/duyvanda/customlooker.git).

## 2. Danh sách file trong gói ZIP [`customLooker.zip`](file:///D:/customLooker/customLooker.zip)

- [`agent.md`](file:///D:/customLooker/agent.md): Tài liệu toàn diện về toàn bộ quy tắc hoạt động, cấu hình, formatter và kiến trúc của biểu đồ.
- [`EXPORT_SANDBOX_AND_WEBVIEW_ANALYSIS.md`](file:///D:/customLooker/EXPORT_SANDBOX_AND_WEBVIEW_ANALYSIS.md): Tài liệu chuyên sâu về cơ chế Sandbox & giải pháp Android WebView.
- [`src/index.js`](file:///D:/customLooker/src/index.js): Mã nguồn bảng JS.
- [`downloader.html`](file:///D:/customLooker/downloader.html): Giao diện xuất Excel kèm chức năng copy JSON Date Range nguyên bản.
- [`manifest.json`](file:///D:/customLooker/manifest.json): Khai báo tài nguyên Community Visualization ở chế độ `"devMode": true`.
- [`index.bundle.js`](file:///D:/customLooker/index.bundle.js): File bundle tối ưu (~30.6 KB).
- [`index.css`](file:///D:/customLooker/index.css): Giao diện bảng.
- [`index.json`](file:///D:/customLooker/index.json): Schema Looker Studio.
- [`package.json`](file:///D:/customLooker/package.json): Cấu hình dependencies npm.
- [`webpack.config.js`](file:///D:/customLooker/webpack.config.js): Cấu hình đóng gói Webpack.
- [`changelog/`](file:///D:/customLooker/changelog): Lịch sử thay đổi và nhật ký chi tiết của dự án.
