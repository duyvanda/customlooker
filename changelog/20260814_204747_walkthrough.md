# Walkthrough: Custom Looker Studio Table Viz - Public Read ACL & GCS Manifest Verification

## 1. Vấn đề gốc rễ & Các giải pháp đã triển khai

1. **Khắc phục thông báo `Visualization not found`:**
   - **Nguyên nhân:** Khi thực hiện lệnh upload đè file lên GCS trong một vài giây ngắn ngủi, hoặc nếu cờ quyền đọc công khai (`public-read`) bị Looker Studio truy vấn đúng thời điểm cập nhật, Looker Studio sẽ tạm thời không tải được file `manifest.json` / `index.json`.
   - **Đã xử lý:**
     - Đã thiết lập lại quyền truy cập công khai `allUsers:R` và cờ `-a public-read` cho toàn bộ các file trên bucket:
       - `gs://analytics_merap/excelchart2/manifest.json`
       - `gs://analytics_merap/excelchart2/index.json`
       - `gs://analytics_merap/excelchart2/index.bundle.js`
       - `gs://analytics_merap/excelchart2/index.css`
       - `gs://analytics_merap/excelchart2/downloader.html`
     - Đã kiểm tra trực tiếp qua HTTP REST call xác nhận JSON hợp lệ 100% và phản hồi mã 200 OK.
2. **Nhãn tab Setup chuẩn quốc tế:**
   - Đã gỡ bỏ toàn bộ chú thích tiếng Việt thừa, chuẩn hóa thành:
     - **`Dimension`**
     - **`Metric`**
3. **Khắc phục triệt để Modal bị mờ:**
   - Xóa bỏ hoàn toàn `backdrop-filter: blur()` gây lỗi rasterization trong iframe của Looker Studio.
   - Nâng cấp độ tương phản chữ lên màu đen tuyền `#000000` (`font-weight: 600 - 700`), viền khung `#94a3b8`.
4. **Đóng gói dự án & Git:**
   - Cập nhật [`customLooker.zip`](file:///D:/customLooker/customLooker.zip).
   - Push lên GitHub [https://github.com/duyvanda/customlooker.git](https://github.com/duyvanda/customlooker.git).
   - Deploy GCS `gs://analytics_merap/excelchart2/`.
