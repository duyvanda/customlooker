# Walkthrough: Custom Looker Studio Table Viz - In-Place Direct Excel Export (Android / Mobile WebView Fix)

## 1. Tóm tắt các thay đổi vừa hoàn thiện

1. **Khắc phục triệt để lỗi "Load mãi không ra file Excel trên Android / In-App WebView":**
   - **Nguyên nhân trước đây:** Khi báo cáo Looker Studio được nhúng (Embed) vào App Android (thông qua Android WebView, Flutter WebView, React Native WebView...), các hàm `window.open()` và cơ chế truyền tin `postMessage` giữa 2 WebViews bị hệ điều hành Android chặn hoặc ngắt kết nối, khiến trang trung gian quay vòng chờ mãi.
   - **Giải pháp xử lý (Giống giải pháp của Echart & BI Merap):**
     - Đã đóng gói trực tiếp thư viện **SheetJS (`xlsx`)** vào trong file bundle chính [`index.bundle.js`](file:///D:/customLooker/index.bundle.js).
     - Khi người dùng bấm **`Xuất Excel (X dòng)`**, hệ thống tạo Workbook và Binary Blob **trực tiếp tại chỗ (Direct In-Place Download)** thông qua `URL.createObjectURL(blob)` hoặc `XLSX.writeFile`.
     - Tải file `.xlsx` về máy ngay lập tức trong 0.1 giây mà **không cần mở bất kỳ tab hay popup trung gian nào**, tương thích 100% trên Android App, iOS, iPad và Desktop PC.
2. **Kích hoạt `"devMode": true`:**
   - Đảm bảo Looker Studio luôn nạp bản cập nhật mới nhất tức thì 0 giây, không bị kẹt cache cứng của Google CDN.
3. **Cập nhật gói ZIP & Triển khai:**
   - Cập nhật [`customLooker.zip`](file:///D:/customLooker/customLooker.zip).
   - Deploy GCS `gs://analytics_merap/excelchart2/`.
   - Push commit mới lên GitHub: [https://github.com/duyvanda/customlooker.git](https://github.com/duyvanda/customlooker.git).

## 2. Danh sách file trong gói ZIP [`customLooker.zip`](file:///D:/customLooker/customLooker.zip)

- [`src/index.js`](file:///D:/customLooker/src/index.js): Mã nguồn bảng JS tích hợp SheetJS xuất file Excel trực tiếp tại chỗ.
- [`manifest.json`](file:///D:/customLooker/manifest.json): Khai báo tài nguyên Community Visualization ở chế độ `"devMode": true`.
- [`index.bundle.js`](file:///D:/customLooker/index.bundle.js): File bundle tối ưu (~304 KB đã bao gồm toàn bộ core engine SheetJS).
- [`index.css`](file:///D:/customLooker/index.css): Giao diện bảng.
- [`downloader.html`](file:///D:/customLooker/downloader.html): Giao diện dự phòng.
- [`index.json`](file:///D:/customLooker/index.json): Schema Looker Studio.
- [`package.json`](file:///D:/customLooker/package.json): Cấu hình dependencies npm.
- [`webpack.config.js`](file:///D:/customLooker/webpack.config.js): Cấu hình đóng gói Webpack.
- [`agent.md`](file:///D:/customLooker/agent.md): Tài liệu toàn diện về toàn bộ quy tắc hoạt động, cấu hình, formatter và kiến trúc của biểu đồ.
- [`changelog/`](file:///D:/customLooker/changelog): Lịch sử thay đổi và nhật ký chi tiết của dự án.
