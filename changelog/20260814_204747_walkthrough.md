# Walkthrough: Custom Looker Studio Table Viz - Streamlined Style Architecture & Column Mapping Display

## 1. Tóm tắt các tinh chỉnh hoàn thiện theo `feedback.md`

1. **Tinh gọn Menu Search Scope:**
   - Đã loại bỏ hoàn toàn danh sách dài `Column 1`..`Column 30` khỏi mục **Search Scope** trong tab Style.
   - Chỉ giữ lại **2 lựa chọn thực tế và trực quan nhất**:
     - `Visible columns (Cột đang hiển thị)`: Quét tìm kiếm trên các cột đang mở.
     - `All columns (Tất cả các cột)`: Quét tìm kiếm trên toàn bộ dữ liệu (kể cả cột đang ẩn runtime).
2. **Hiển thị Đối Chiếu Vị Trí Cột (Column Position Mapping):**
   - Trong popup `👁️ Cột hiển thị & Thứ tự Style` (và tooltip trên nút toolbar), hiển thị rõ ràng bảng đối chiếu:
     - `Column 1 (c0) — <Tên Cột 1>`
     - `Column 2 (c1) — <Tên Cột 2>`
     - `Column 3 (c2) — <Tên Cột 3>`...
   - Giúp người thiết lập báo cáo khi vào tab Style (chọn **Sắp xếp mặc định** hoặc **Quy tắc tô màu Rules 1–5**) biết chính xác ngay `Column X` ứng với trường dữ liệu nào mà không cần phải đoán.
3. **Cố định Base Columns Slots (`c0`..`c29`):**
   - Việc ẩn/hiện cột tạm thời tại runtime tuyệt đối không làm xáo trộn slot của các cột còn lại.
4. **Cập nhật gói ZIP & Triển khai:**
   - Cập nhật [`customLooker.zip`](file:///D:/customLooker/customLooker.zip).
   - Deploy GCS `gs://analytics_merap/excelchart2/`.
   - Push commit mới lên GitHub: [https://github.com/duyvanda/customlooker.git](https://github.com/duyvanda/customlooker.git).

## 2. Danh sách file trong gói ZIP [`customLooker.zip`](file:///D:/customLooker/customLooker.zip)

- [`index.json`](file:///D:/customLooker/index.json): Schema Looker Studio tinh gọn Search Scope (2 options) và hỗ trợ đầy đủ 30 cột cho Sort & Conditional Rules 1–5.
- [`src/index.js`](file:///D:/customLooker/src/index.js): Mã nguồn bảng JS hiển thị đối chiếu vị trí cột trong popup và xử lý logic Looker native.
- [`index.css`](file:///D:/customLooker/index.css): Giao diện sắc nét, nền trong suốt, không skeleton.

- [`package.json`](file:///D:/customLooker/package.json): Cấu hình dependencies npm.
- [`webpack.config.js`](file:///D:/customLooker/webpack.config.js): Cấu hình đóng gói Webpack.
- [`index.bundle.js`](file:///D:/customLooker/index.bundle.js): File bundle tối ưu (~28.1 KB).
