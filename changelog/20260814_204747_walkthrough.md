# Walkthrough: Custom Looker Studio Table Viz - Unified Accent-Insensitive Search & Looker Date Formatting

## 1. Vấn đề gốc rễ & Các giải pháp đã triển khai

1. **Lỗi iframe Sandbox (`Download is disallowed`):**
   - Đã giải quyết triệt để thông qua kiến trúc trang trung gian [`downloader.html`](file:///D:/customLooker/downloader.html) với giao diện tinh gọn, hỗ trợ xuất Excel (`.xlsx`), CSV (UTF-8 có BOM), và Copy JSON.
2. **Khắc phục lỗi file Excel rỗng:**
   - Sử dụng phương thức `XLSX.utils.aoa_to_sheet([headers, ...rows])` (ma trận 2 chiều) đảm bảo chính xác 100% tất cả dòng và cột theo cấu hình hiển thị thực tế.
3. **Đồng bộ chuẩn hóa tìm kiếm và so sánh điều kiện với `remove_accents()` từ [`D:\django_apps\rest\frontend1\src\utils\string.js`](file:///D:/django_apps/rest/frontend1/src/utils/string.js):**
   - Tích hợp hàm:
     ```javascript
     function remove_accents(str) {
         if (!str) return '';
         return String(str)
             .normalize('NFD')
             .toLowerCase()
             .replace(/[\u0300-\u036f]/g, '')
             .replace(/đ/g, 'd');
     }
     ```
   - **Tìm kiếm đa từ khóa & không dấu:** Khi tìm `duy`, `thinh`, `le`, `hoan`, `duc`, hệ thống tự động tìm chính xác cả `Duy`, `Thịnh`, `Lê`, `Hoàn`, `Đức`...
   - **So sánh quy tắc điều kiện (contains, equals, startsWith):** Tự động bỏ dấu và không phân biệt chữ hoa/thường, đảm bảo độ khớp 100%.
4. **Sửa triệt để lỗi ép kiểu Ngày Tháng `YYYYMMDD` của Looker Studio:**
   - Hàm `isDateValue()` kết hợp `formatDateValue()` tự động chuyển chuỗi `YYYYMMDD` (ví dụ `19000420`, `20080101`, `20110301`) sang dạng chuẩn Việt Nam `dd-mm-yyyy` (`20-04-1900`, `01-01-2008`, `01-03-2011`).
5. **Bộ Quy Tắc Điều Kiện Động Toàn Diện trong Modal `⚙️ Cột Bảng & Màu Sắc`:**
   - Quản lý 100% trực quan với đầy đủ toán tử `Chứa từ khóa (Contains)`, `Bằng chính xác (=)`, `Lớn hơn (>)`, `Nhỏ hơn (<)`, `>=`, `<=`, `Số dương (>=0)`, `Số âm (<0)`.
6. **Đóng gói dự án & Git:**
   - Cập nhật [`customLooker.zip`](file:///D:/customLooker/customLooker.zip).
   - Push lên GitHub [https://github.com/duyvanda/customlooker.git](https://github.com/duyvanda/customlooker.git).
   - Deploy GCS `gs://analytics_merap/excelchart2/`.
