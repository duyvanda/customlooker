# Walkthrough: Custom Looker Studio Table Viz - Setup Badge Fields & Style Condition Formatting

## 1. Vấn đề gốc rễ & Các giải pháp đã triển khai

1. **Lỗi iframe Sandbox (`Download is disallowed`):**
   - Đã giải quyết triệt để thông qua kiến trúc trang trung gian [`downloader.html`](file:///D:/customLooker/downloader.html) với giao diện tinh gọn, hỗ trợ xuất Excel (`.xlsx`), CSV (UTF-8 có BOM), và Copy JSON.
2. **Khắc phục lỗi file Excel rỗng:**
   - Sử dụng phương thức `XLSX.utils.aoa_to_sheet([headers, ...rows])` (ma trận 2 chiều) đảm bảo chính xác 100% tất cả dòng và cột theo cấu hình hiển thị thực tế.
3. **Cơ chế Chọn Cột bên Setup & Cấu hình Condition bên Style hoàn hảo:**
   - **Bên Tab Setup (Dữ liệu):** Bổ sung slot chuyên dụng **`🏷️ Cột hiển thị Badge (Kéo cột cần tạo Badge vào đây)`**.
     - Khi Admin muốn cột nào hiển thị dạng Badge (như `JobType`, `Trạng thái`, `Status`), chỉ cần kéo cột đó vào ô `badgeFields`.
     - Các cột bình thường khác (như `Name`, `PIC`, `Description`) sẽ **hoàn toàn giữ nguyên text thuần**, không bao giờ bị áp badge nhầm lẫn!
   - **Bên Tab Style (Giao diện):** Cung cấp bộ cài đặt **`🎨 Điều Kiện Tô Màu & Badge (Conditional Formatting)`**:
     - `Từ khóa Badge Xanh Lá (✓ Success)`
     - `Từ khóa Badge Đỏ (✕ Danger)`
     - `Từ khóa Badge Vàng (⏳ Warning)`
     - `Từ khóa Badge Xanh Dương (Info)`
     - `Các giá trị khác trong Cột Badge`: Tùy chọn hiển thị `Thẻ Badge Xám` hoặc `Chữ thường`.
     - `Tô màu số liệu: Dương Xanh / Âm Đỏ`.
4. **Sửa triệt để lưu Ẩn/Hiện và Thứ Tự Cột trong Modal `⚙️ Cột Bảng`:**
   - Hàm `syncInputsBeforeMove()` quét trực tiếp toàn bộ DOM các checkbox, input label, dropdown format và mảng cột đã được sắp xếp; lưu đồng thời vào biến bộ nhớ `userColumnConfigs` và `localStorage`.
5. **Cài đặt số dòng mặc định từ Admin Panel:**
   - Hỗ trợ các mức từ 10 đến 1000 và Tất cả dòng trong Tab Style.
6. **Đóng gói dự án & Git:**
   - Cập nhật [`customLooker.zip`](file:///D:/customLooker/customLooker.zip).
   - Push lên GitHub [https://github.com/duyvanda/customlooker.git](https://github.com/duyvanda/customlooker.git).
   - Deploy GCS `gs://analytics_merap/excelchart2/`.

## 2. Danh sách file trong gói ZIP & Dự án

- [`src/index.js`](file:///D:/customLooker/src/index.js): Toàn bộ logic Table Viz, Modal Tùy chỉnh cột, BadgeFields Targeter, Style Rules Parser, Admin Master PageSize Sync, Formatter, Sort & Export.
- [`downloader.html`](file:///D:/customLooker/downloader.html): Giao diện tải file Excel, CSV & Copy JSON.
- [`index.css`](file:///D:/customLooker/index.css): Toàn bộ CSS giao diện Inter font, Modal Popup, Table Variants, Densities, Badges, Mono font & Scrollbar.
- [`index.json`](file:///D:/customLooker/index.json): Khai báo Data Setup (Dimensions, Metrics, badgeFields, searchFields) và Style Panel (defaultPageSize, conditionalBadges keywords, Density, Variant, Font Size, STT, Wrap, Search, Col Config).
- [`manifest.json`](file:///D:/customLooker/manifest.json): Khai báo tài nguyên Community Visualization.
- [`package.json`](file:///D:/customLooker/package.json): Cấu hình dependencies npm.
- [`webpack.config.js`](file:///D:/customLooker/webpack.config.js): Cấu hình đóng gói Webpack.
- [`index.bundle.js`](file:///D:/customLooker/index.bundle.js): File bundle đã build sẵn để deploy (~32.6 KB).
- [`agent.md`](file:///D:/customLooker/agent.md): Tài liệu tổng quan kiến trúc, luồng hoạt động và hướng dẫn sử dụng.
