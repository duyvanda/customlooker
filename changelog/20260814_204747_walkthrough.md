# Walkthrough: Custom Looker Studio Table Viz - Full Ruleset Documentation Update

## 1. Vấn đề gốc rễ & Các giải pháp đã triển khai

1. **Cập nhật toàn bộ các quy tắc hoạt động của biểu đồ vào [`agent.md`](file:///D:/customLooker/agent.md):**
   - **Mục 3.1: Quy tắc Khai báo Schema Looker Studio:** Cấu trúc `concepts.elements` chứa `Dimension` và `Metric` chuẩn Looker Studio Community Viz SDK, danh sách toàn bộ thuộc tính trong tab Style (`defaultPageSize`, `rowDensity`, `tableVariant`, `fontSize`, `showSTT`, `textWrap`, `showSearch`, `showColConfig`, `searchPlaceholder`).
   - **Mục 3.2: Quy tắc Tùy Chỉnh Cột (Tab 1):** Cơ chế lưu `localStorage`, ẩn/hiện, đổi tên hiển thị (label), di chuyển thứ tự và 11 kiểu định dạng (Date các loại, Number VN, Currency, Percent, Monospace, Badge).
   - **Mục 3.3: Quy tắc Tô Màu & Gắn Badge Động (Tab 2):** Phạm vi áp dụng từng cột hoặc tất cả cột, 9 toán tử so sánh (`contains`, `equals`, `startsWith`, `>`, `<`, `>=`, `<=`, `pos`, `neg`), 10 kiểu hiển thị (Badge Xanh/Đỏ/Vàng/Info/Xám, Màu chữ Xanh/Đỏ/Vàng/Xanh Dương/Dương Xanh Âm Đỏ).
   - **Mục 3.4: Quy tắc Nhận Diện Ngày Tháng:** Intercept chuỗi 8 số `YYYYMMDD` và DateTime trước Numeric parser để tránh lỗi format hàng nghìn, căn giữa tự động.
   - **Mục 3.5: Quy tắc Tìm Kiếm Tiếng Việt:** Thuật toán chuẩn hóa `remove_accents` bỏ dấu tiếng Việt, tìm kiếm đa từ trên tất cả các cột, duy trì con trỏ và tiêu điểm khi gõ.
   - **Mục 3.6: Quy tắc Tối Ưu Độ Nét & Giao Diện:** Loại bỏ `backdrop-filter: blur()`, màu chữ `#0f172a` / `#000000`, kích hoạt `window.focus()` khi click vào chart ở Edit Mode.
2. **Đóng gói dự án & Git:**
   - Cập nhật [`customLooker.zip`](file:///D:/customLooker/customLooker.zip).
   - Push lên GitHub [https://github.com/duyvanda/customlooker.git](https://github.com/duyvanda/customlooker.git).
   - Deploy GCS `gs://analytics_merap/excelchart2/`.

## 2. Danh sách file trong gói ZIP & Dự án

- [`agent.md`](file:///D:/customLooker/agent.md): Tài liệu toàn diện về toàn bộ quy tắc hoạt động, cấu hình, formatter và kiến trúc của biểu đồ.
- [`src/index.js`](file:///D:/customLooker/src/index.js): Toàn bộ logic Table Viz, Modal Tùy chỉnh cột gọn gàng, Nút Hủy và Lưu chuẩn xác.
- [`downloader.html`](file:///D:/customLooker/downloader.html): Giao diện tải file Excel, CSV & Copy JSON.
- [`index.css`](file:///D:/customLooker/index.css): Toàn bộ CSS siêu nét, không blur, màu đen đậm `#000000`, viền sắc nét.
- [`index.json`](file:///D:/customLooker/index.json): Khai báo Data Setup chuẩn cấu trúc concepts.elements (`Dimension`, `Metric`) và Style Panel.
- [`manifest.json`](file:///D:/customLooker/manifest.json): Khai báo tài nguyên Community Visualization.
- [`package.json`](file:///D:/customLooker/package.json): Cấu hình dependencies npm.
- [`webpack.config.js`](file:///D:/customLooker/webpack.config.js): Cấu hình đóng gói Webpack.
- [`index.bundle.js`](file:///D:/customLooker/index.bundle.js): File bundle đã build sẵn để deploy (~42.0 KB).
