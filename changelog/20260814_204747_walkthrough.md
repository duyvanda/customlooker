# Walkthrough: Custom Looker Studio Table Viz - Admin Style Badges & Fixed Column Persistence

## 1. Vấn đề gốc rễ & Các giải pháp đã triển khai

1. **Lỗi iframe Sandbox (`Download is disallowed`):**
   - Đã giải quyết triệt để thông qua kiến trúc trang trung gian [`downloader.html`](file:///D:/customLooker/downloader.html) với giao diện tinh gọn, hỗ trợ xuất Excel (`.xlsx`), CSV (UTF-8 có BOM), và Copy JSON.
2. **Khắc phục lỗi file Excel rỗng:**
   - Sử dụng phương thức `XLSX.utils.aoa_to_sheet([headers, ...rows])` (ma trận 2 chiều) đảm bảo chính xác 100% tất cả dòng và cột theo cấu hình hiển thị thực tế.
3. **Đưa toàn bộ phần Tô Màu & Gắn Thẻ Badge vào Tab Style của Looker Studio (Admin Setup):**
   - **Mục tiêu:** Giúp Admin có thể thiết lập từ khóa tô màu / gắn badge trực tiếp ngay trong giao diện Looker Studio mà không phụ thuộc vào `localStorage` của trình duyệt từng người dùng. Các cài đặt này được lưu vĩnh viễn vào file báo cáo Looker Studio.
   - **Các tùy chọn trong Tab Style:**
     - **Từ khóa Badge Xanh Lá (`✓ Success`):** Mặc định `Done, Active, Thành công, Hoàn tất, Đạt`
     - **Từ khóa Badge Đỏ (`✕ Danger`):** Mặc định `OFF, Fail, Failed, Cancel, Hủy, Thất bại, Late`
     - **Từ khóa Badge Vàng (`⏳ Warning`):** Mặc định `Pending, Chờ xử lý, Đang xử lý, Warning`
     - **Từ khóa Badge Xanh Dương (`Info`):** Mặc định `CH-replace, Staging, Info`
     - **Từ khóa Badge Xám (`Gray`):** Mặc định `None, Null, N/A`
     - **Tự động tô màu Số dương Xanh / Số âm Đỏ:** Bật/Tắt checkbox linh hoạt.
4. **Sửa triệt để lỗi lưu Ẩn/Hiện và Thứ Tự Cột trong Modal `⚙️ Cột Bảng`:**
   - **Nguyên nhân cũ:** Khi nhấn nút `Lưu & Áp Dụng`, các giá trị checkbox và vị trí hoán đổi cột không được đọc đồng bộ từ DOM và bị hàm `renderTable()` ghi đè lại schema ban đầu.
   - **Giải pháp:** Khi bấm `Lưu & Áp Dụng`, hàm `syncInputsBeforeMove()` quét trực tiếp toàn bộ DOM các checkbox, input label, dropdown format và mảng cột đã được sắp xếp; lưu đồng thời vào biến bộ nhớ `userColumnConfigs` và `localStorage`. Hàm `syncColumnConfigsWithFields()` đảm bảo giữ nguyên 100% thứ tự và trạng thái ẩn hiện khi chuyển trang hay lọc tìm kiếm.
5. **Cài đặt số dòng mặc định từ Admin Panel:**
   - Hỗ trợ các mức từ 10 đến 1000 và Tất cả dòng trong Tab Style.
6. **Đóng gói dự án & Git:**
   - Cập nhật [`customLooker.zip`](file:///D:/customLooker/customLooker.zip).
   - Push lên GitHub [https://github.com/duyvanda/customlooker.git](https://github.com/duyvanda/customlooker.git).
   - Deploy GCS `gs://analytics_merap/excelchart2/`.

## 2. Danh sách file trong gói ZIP & Dự án

- [`src/index.js`](file:///D:/customLooker/src/index.js): Toàn bộ logic Table Viz, Modal Tùy chỉnh cột, Style Rules Parser, Admin Master PageSize Sync, Formatter, Sort & Export.
- [`downloader.html`](file:///D:/customLooker/downloader.html): Giao diện tải file Excel, CSV & Copy JSON.
- [`index.css`](file:///D:/customLooker/index.css): Toàn bộ CSS giao diện Inter font, Modal Popup, Table Variants, Densities, Badges, Mono font & Scrollbar.
- [`index.json`](file:///D:/customLooker/index.json): Khai báo Data Setup và Style Panel (defaultPageSize, Density, Variant, Font Size, STT, Wrap, Search, Col Config, conditionalBadges keywords).
- [`manifest.json`](file:///D:/customLooker/manifest.json): Khai báo tài nguyên Community Visualization.
- [`package.json`](file:///D:/customLooker/package.json): Cấu hình dependencies npm.
- [`webpack.config.js`](file:///D:/customLooker/webpack.config.js): Cấu hình đóng gói Webpack.
- [`index.bundle.js`](file:///D:/customLooker/index.bundle.js): File bundle đã build sẵn để deploy (~32.1 KB).
- [`agent.md`](file:///D:/customLooker/agent.md): Tài liệu tổng quan kiến trúc, luồng hoạt động và hướng dẫn sử dụng.
