# Walkthrough: Custom Looker Studio Table Viz - Fix Data Schema Hierarchy & Complete Optimization

## 1. Vấn đề gốc rễ & Các giải pháp đã triển khai

1. **Khắc phục lỗi `TypeError: Cannot read properties of undefined (reading 'hierarchy')` trong `pm_ng2report`:**
   - **Nguyên nhân:** Trong file [`index.json`](file:///D:/customLooker/index.json), mảng `"data"` trước đó đã bọc thêm 1 cấp category `"concepts"` với `"elements": [...]` (giống như format của `"style"`). Theo đúng đặc tả chuẩn của Looker Studio Community Visualization SDK, mảng `"data"` phải chứa trực tiếp các đối tượng `DIMENSION` và `METRIC` ở cấp 1 mà không được lồng `"elements"`. Khi Looker Studio duyệt cây dữ liệu để xử lý tính năng Drill-down Hierarchy (phân cấp thứ bậc), nó không tìm thấy thuộc tính cấu hình ở cấp 1 nên Angular của Looker Studio bị crash.
   - **Đã fix:**
     - Chuẩn hóa cấu trúc `"data"` trong `index.json` theo đúng đặc tả kỹ thuật của Google:
       ```json
       "data": [
           {
               "id": "dimensions",
               "label": "Dimensions (Các cột hiển thị)",
               "type": "DIMENSION",
               "options": { "min": 0, "max": 50 }
           },
           {
               "id": "metrics",
               "label": "Metrics (Các cột số liệu)",
               "type": "METRIC",
               "options": { "min": 0, "max": 50 }
           }
       ]
       ```
2. **Gọn gàng Modal `⚙️ Cột Bảng & Màu Sắc`:**
   - Đã **xóa bỏ cột `Màu cột (Color)`** trong Tab 1 `📋 Cấu Hình Cột` để giao diện thoáng, tinh gọn.
   - Các nút dưới chân Modal được rút gọn chuẩn mực: **`Hủy`**, **`Lưu`**, **`🔄 Khôi phục mặc định`**.
3. **Khắc phục chữ bảng bị mờ:**
   - Cập nhật màu chữ đen đậm cao cấp (`#0f172a`), tăng độ dày nét chữ (`font-weight: 450 - 700`).
   - Tối ưu rendering trên màn hình độ phân giải cao (`-webkit-font-smoothing: antialiased; -moz-osx-font-smoothing: grayscale`).
4. **Đồng bộ chuẩn hóa tìm kiếm và so sánh điều kiện với `remove_accents()`:**
   - Tìm kiếm tiếng Việt không dấu và khớp quy tắc linh hoạt.
5. **Định dạng Ngày Tháng chuẩn Việt Nam `dd-mm-yyyy`:**
   - Tự động nhận diện chuỗi `YYYYMMDD` (8 chữ số của Looker Studio) và chuyển thành `01-01-2008`, `01-03-2011`, `20-04-1900`.
6. **Đóng gói dự án & Git:**
   - Cập nhật [`customLooker.zip`](file:///D:/customLooker/customLooker.zip).
   - Push lên GitHub [https://github.com/duyvanda/customlooker.git](https://github.com/duyvanda/customlooker.git).
   - Deploy GCS `gs://analytics_merap/excelchart2/`.

## 2. Danh sách file trong gói ZIP & Dự án

- [`index.json`](file:///D:/customLooker/index.json): Khai báo Data Setup chuẩn cấu trúc cấp 1 (Dimensions, Metrics) và Style Panel.
- [`src/index.js`](file:///D:/customLooker/src/index.js): Toàn bộ logic Table Viz, Modal Tùy chỉnh cột gọn gàng, Nút Hủy và Lưu chuẩn xác, Độ tương phản cao.
- [`downloader.html`](file:///D:/customLooker/downloader.html): Giao diện tải file Excel, CSV & Copy JSON.
- [`index.css`](file:///D:/customLooker/index.css): Toàn bộ CSS siêu nét, High-DPI font rendering, màu đen đậm `#0f172a`, viền sắc nét, Modal Popup Tabs & Buttons.
- [`manifest.json`](file:///D:/customLooker/manifest.json): Khai báo tài nguyên Community Visualization.
- [`package.json`](file:///D:/customLooker/package.json): Cấu hình dependencies npm.
- [`webpack.config.js`](file:///D:/customLooker/webpack.config.js): Cấu hình đóng gói Webpack.
- [`index.bundle.js`](file:///D:/customLooker/index.bundle.js): File bundle đã build sẵn để deploy (~42.0 KB).
- [`agent.md`](file:///D:/customLooker/agent.md): Tài liệu tổng quan kiến trúc, luồng hoạt động và hướng dẫn sử dụng.
