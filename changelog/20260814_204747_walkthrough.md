# Walkthrough: Custom Looker Studio Table Viz - Full Dynamic Conditions Engine (> < = contains)

## 1. Vấn đề gốc rễ & Các giải pháp đã triển khai

1. **Lỗi iframe Sandbox (`Download is disallowed`):**
   - Đã giải quyết triệt để thông qua kiến trúc trang trung gian [`downloader.html`](file:///D:/customLooker/downloader.html) với giao diện tinh gọn, hỗ trợ xuất Excel (`.xlsx`), CSV (UTF-8 có BOM), và Copy JSON.
2. **Khắc phục lỗi file Excel rỗng:**
   - Sử dụng phương thức `XLSX.utils.aoa_to_sheet([headers, ...rows])` (ma trận 2 chiều) đảm bảo chính xác 100% tất cả dòng và cột theo cấu hình hiển thị thực tế.
3. **Bộ Quy Tắc Điều Kiện Tô Màu & Badge Động Toàn Diện (> < = contain startsWith pos neg):**
   - **Hỗ trợ cấu hình trực tiếp trong Tab Style của Looker Studio (Dành cho Admin lưu vĩnh viễn):**
     - Cung cấp ô **`Quy tắc động (Admin DSL)`** hỗ trợ cú pháp siêu linh hoạt:
       - `JobType = OFF : badge_danger`
       - `JobType = Staging : badge_info`
       - `Status contain Done : badge_success`
       - `Doanh thu > 1000 : color_green`
       - `Lợi nhuận < 0 : color_red`
       - Hoặc ngắn gọn: `OFF:badge_danger, Staging:badge_info, >1000:color_green, <0:color_red`
   - **Hỗ trợ cấu hình trực quan trong Modal `⚙️ Cột Bảng & Màu Sắc` (Tab `🎨 Quy Tắc Tô Màu & Badge Động`):**
     - Chọn cột áp dụng (`★ Tất cả cột` hoặc chọn cột cụ thể như `JobType`, `PIC`, `Name`...).
     - Chọn toán tử điều kiện: `Chứa từ khóa (Contains)`, `Bằng chính xác (= Equals)`, `Bắt đầu bằng (Starts with)`, `Lớn hơn (>)`, `Nhỏ hơn (<)`, `Lớn hơn hoặc bằng (>=)`, `Nhỏ hơn hoặc bằng (<=)`, `Số dương (>=0)`, `Số âm (<0)`.
     - Nhập giá trị so sánh.
     - Chọn kiểu hiển thị: `Badge Xanh Lá`, `Badge Đỏ`, `Badge Vàng`, `Badge Xanh Dương`, `Badge Xám`, `Chữ Xanh Lá`, `Chữ Đỏ`, `Chữ Vàng Cam`, `Chữ Xanh Dương`, `Dương Xanh - Âm Đỏ`.
     - Nút `+ Thêm Quy Tắc` và `🗑️ Xóa` lưu trực tiếp vào `localStorage`.
4. **Sửa triệt để lưu Ẩn/Hiện và Thứ Tự Cột trong Modal:**
   - Hàm `syncInputsBeforeMove()` quét trực tiếp toàn bộ DOM các checkbox, input label, dropdown format và mảng cột đã được sắp xếp; lưu đồng thời vào biến bộ nhớ `userColumnConfigs` và `localStorage`.
5. **Cài đặt số dòng mặc định từ Admin Panel:**
   - Hỗ trợ các mức từ 10 đến 1000 và Tất cả dòng trong Tab Style.
6. **Đóng gói dự án & Git:**
   - Cập nhật [`customLooker.zip`](file:///D:/customLooker/customLooker.zip).
   - Push lên GitHub [https://github.com/duyvanda/customlooker.git](https://github.com/duyvanda/customlooker.git).
   - Deploy GCS `gs://analytics_merap/excelchart2/`.

## 2. Danh sách file trong gói ZIP & Dự án

- [`src/index.js`](file:///D:/customLooker/src/index.js): Toàn bộ logic Table Viz, Modal Tùy chỉnh cột, Full Dynamic Condition Rules Engine (> < = contain), Admin Master PageSize Sync, Formatter, Sort & Export.
- [`downloader.html`](file:///D:/customLooker/downloader.html): Giao diện tải file Excel, CSV & Copy JSON.
- [`index.css`](file:///D:/customLooker/index.css): Toàn bộ CSS giao diện Inter font, Modal Popup Tabs, Table Variants, Densities, Badges, Mono font & Scrollbar.
- [`index.json`](file:///D:/customLooker/index.json): Khai báo Data Setup và Style Panel (defaultPageSize, customRulesText, highlightPosNeg, Density, Variant, Font Size, STT, Wrap, Search, Col Config).
- [`manifest.json`](file:///D:/customLooker/manifest.json): Khai báo tài nguyên Community Visualization.
- [`package.json`](file:///D:/customLooker/package.json): Cấu hình dependencies npm.
- [`webpack.config.js`](file:///D:/customLooker/webpack.config.js): Cấu hình đóng gói Webpack.
- [`index.bundle.js`](file:///D:/customLooker/index.bundle.js): File bundle đã build sẵn để deploy (~42.1 KB).
- [`agent.md`](file:///D:/customLooker/agent.md): Tài liệu tổng quan kiến trúc, luồng hoạt động và hướng dẫn sử dụng.
