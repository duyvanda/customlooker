# Walkthrough: Custom Looker Studio Table Viz - Full Native-Like Features

## 1. Vấn đề gốc rễ & Các giải pháp đã triển khai

1. **Lỗi iframe Sandbox (`Download is disallowed`):**
   - Đã giải quyết triệt để thông qua kiến trúc trang trung gian [`downloader.html`](file:///D:/customLooker/downloader.html) với giao diện tinh gọn, hỗ trợ xuất Excel (`.xlsx`), CSV (UTF-8 có BOM), và Copy JSON.
2. **Khắc phục lỗi file Excel rỗng:**
   - Sử dụng phương thức `XLSX.utils.aoa_to_sheet([headers, ...rows])` (ma trận 2 chiều) đảm bảo chính xác 100% tất cả dòng và cột.
3. **Hiển thị Skeleton Loading rõ ràng (Visible Skeleton):**
   - Nhúng CSS Animation Shimmer trực tiếp và thiết lập thời gian hiển thị 700ms mượt mà trước khi load bảng.
4. **Nâng cấp bộ tính năng Native-Like hoàn chỉnh (theo feedback2.md):**
   - **Sort Cột Đa Kiểu (Multi-type Sorting):** Click trực tiếp vào `<th>` để đảo chiều sort (ASC `▲` / DESC `▼` / Default `↕`), tự động nhận diện so sánh Number, Date và Tiếng Việt (`Intl.Collator`).
   - **Phân trang Client-side (Pagination):** Tùy chọn 10, 25, 50, 100 dòng hoặc "Tất cả", kèm nút điều hướng thông minh (‹ Trước, các trang 1, 2, 3..., Sau ›).
   - **Tìm kiếm nhanh (Quick Search):** Ô input tìm kiếm realtime lọc dữ liệu ngay lập tức trên toàn bộ các cột.
   - **Sticky Header:** Cố định tiêu đề cột khi cuộn bảng dọc.
   - **Conditional Formatting:** Tự động gắn nhãn Badge màu cho các trạng thái phổ biến (Success, Fail, Warning, Pending...) và hiển thị số âm màu đỏ nổi bật.
   - **Xuất Excel toàn bộ Dataset:** Khi đang ở bất kỳ trang nào, nút bấm xuất file Excel vẫn xuất **toàn bộ dữ liệu** của dataset, không bị giới hạn bởi trang hiện tại.
5. **Đóng gói dự án & Tài liệu tổng quan:**
   - Đã tạo tài liệu tổng quan toàn bộ dự án [`agent.md`](file:///D:/customLooker/agent.md).
   - Đã tạo file nén [`customLooker.zip`](file:///D:/customLooker/customLooker.zip) chứa đầy đủ mã nguồn, cấu hình và tài liệu.
6. **Đẩy mã nguồn lên Git & Triển khai GCS:**
   - Đã deploy toàn bộ file lên GCS `gs://analytics_merap/excelchart2/`.
   - Đã commit bằng tiếng Việt và push thành công lên GitHub tại [https://github.com/duyvanda/customlooker.git](https://github.com/duyvanda/customlooker.git) (branch `main`).

## 2. Danh sách file trong gói ZIP & Dự án

- [`src/index.js`](file:///D:/customLooker/src/index.js): Mã nguồn JavaScript xử lý tương tác Looker Studio, Sorting, Pagination, Search, Export & Skeleton.
- [`downloader.html`](file:///D:/customLooker/downloader.html): Giao diện tải file Excel, CSV & Copy JSON.
- [`index.css`](file:///D:/customLooker/index.css): Định kiểu bảng, Sticky header, Badge màu, Search, Pagination và Skeleton.
- [`index.json`](file:///D:/customLooker/index.json): Cấu hình các trường dữ liệu cho bảng.
- [`manifest.json`](file:///D:/customLooker/manifest.json): Khai báo tài nguyên Community Visualization.
- [`package.json`](file:///D:/customLooker/package.json): Cấu hình dependencies npm.
- [`webpack.config.js`](file:///D:/customLooker/webpack.config.js): Cấu hình đóng gói Webpack.
- [`index.bundle.js`](file:///D:/customLooker/index.bundle.js): File bundle đã build sẵn để deploy (~18.7 KB).
- [`agent.md`](file:///D:/customLooker/agent.md): Tài liệu tổng quan kiến trúc, luồng hoạt động và hướng dẫn sử dụng.
- [`feedback.md`](file:///D:/customLooker/feedback.md) & [`feedback2.md`](file:///D:/customLooker/feedback2.md): Bản ghi nhận xét và các đề xuất nâng cấp.
