# Walkthrough: Custom Looker Studio Table Viz - Configurable Search & Column Targeting

## 1. Vấn đề gốc rễ & Các giải pháp đã triển khai

1. **Lỗi iframe Sandbox (`Download is disallowed`):**
   - Đã giải quyết triệt để thông qua kiến trúc trang trung gian [`downloader.html`](file:///D:/customLooker/downloader.html) với giao diện tinh gọn, hỗ trợ xuất Excel (`.xlsx`), CSV (UTF-8 có BOM), và Copy JSON.
2. **Khắc phục lỗi file Excel rỗng:**
   - Sử dụng phương thức `XLSX.utils.aoa_to_sheet([headers, ...rows])` (ma trận 2 chiều) đảm bảo chính xác 100% tất cả dòng và cột.
3. **Hiển thị Skeleton Loading rõ ràng (Visible Skeleton):**
   - Nhúng CSS Animation Shimmer trực tiếp và thiết lập thời gian hiển thị 700ms mượt mà trước khi load bảng.
4. **Bộ tính năng Table Native-Like:**
   - Sort cột đa kiểu (Number, Date, Vietnamese text).
   - Phân trang Client-side (10, 25, 50, 100, 250, 500, 1000, Tất cả).
   - Sticky Header cố định khi cuộn dọc.
   - Xuất Excel toàn bộ Dataset đã filter.
5. **Tìm kiếm nhanh có thể cấu hình (Configurable Search & Column Target):**
   - **Tùy biến trong Style Panel của Looker Studio:** Thêm mục **"Cài đặt Tìm kiếm & Bảng"** trong tab Style với các tùy chọn:
     - `Bật ô tìm kiếm nhanh` (Checkbox bật/tắt).
     - `Gợi ý tìm kiếm (Placeholder)` (Cho phép tùy chỉnh text như "Tìm mã, tên khách...").
   - **Chọn cột tìm kiếm trực tiếp trên thanh công cụ (Interactive Column Selector):** Tích hợp dropdown ngay cạnh ô tìm kiếm:
     - `Tất cả cột`: Tìm kiếm đa từ khóa trên toàn bộ các cột.
     - `Cột cụ thể (Mã khách / Tên khách...)`: Giới hạn tìm kiếm chính xác trên cột được chọn.
6. **Đóng gói dự án & Git:**
   - Cập nhật [`customLooker.zip`](file:///D:/customLooker/customLooker.zip).
   - Push lên GitHub [https://github.com/duyvanda/customlooker.git](https://github.com/duyvanda/customlooker.git).
   - Deploy GCS `gs://analytics_merap/excelchart2/`.

## 2. Danh sách file trong gói ZIP & Dự án

- [`src/index.js`](file:///D:/customLooker/src/index.js): Mã nguồn JavaScript xử lý tương tác Looker Studio, Sorting, Pagination, Configurable Search & Skeleton.
- [`downloader.html`](file:///D:/customLooker/downloader.html): Giao diện tải file Excel, CSV & Copy JSON.
- [`index.css`](file:///D:/customLooker/index.css): Giao diện chuẩn Inter font, Slim Scrollbar, Search Group & Sticky Header.
- [`index.json`](file:///D:/customLooker/index.json): Khai báo các trường dữ liệu và cấu hình Style tìm kiếm.
- [`manifest.json`](file:///D:/customLooker/manifest.json): Khai báo tài nguyên Community Visualization.
- [`package.json`](file:///D:/customLooker/package.json): Cấu hình dependencies npm.
- [`webpack.config.js`](file:///D:/customLooker/webpack.config.js): Cấu hình đóng gói Webpack.
- [`index.bundle.js`](file:///D:/customLooker/index.bundle.js): File bundle đã build sẵn để deploy (~20.3 KB).
- [`agent.md`](file:///D:/customLooker/agent.md): Tài liệu tổng quan kiến trúc, luồng hoạt động và hướng dẫn sử dụng.
