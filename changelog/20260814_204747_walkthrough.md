# Walkthrough: Custom Looker Studio Table Viz - Targeted Filter Dimension Extraction

## 1. Tóm tắt các thay đổi vừa hoàn thiện

1. **Chuẩn hóa đối tượng trích xuất bộ lọc:**
   - **Vấn đề trước đây:** Code tự động duyệt qua tất cả Dimension có trong bảng (`Khối`, `dienthoai`, `cumphucvu`, `loaihld`...) khiến JSON xuất ra gom toàn bộ các cột thay vì chỉ lấy đúng cột mà người dùng đang lọc (`hovatenfullname`).
   - **Giải pháp chính xác:**
     - Liên kết trực tiếp với mục **`Search Dimension`** trong tab **Setup**.
     - Khi bạn chọn cột nào trong `Search Dimension` (ví dụ: **`hovatenfullname`** như trên màn hình Setup), hệ thống sẽ **chỉ lấy duy nhất** giá trị của cột đó để đưa vào JSON và chuỗi text bộ lọc:
       ```json
       {
         "dateRange": {
           "startDate": "2026-08-01",
           "endDate": "2026-08-31"
         },
         "dimensions": {
           "hovatenfullname": ["ABC", "XYZ"]
         }
       }
       ```
       và chuỗi Text:
       `startdate=2026-08-01 and enddate=2026-08-31 and hovatenfullname=ABC,XYZ`
2. **Cập nhật gói ZIP & Triển khai:**
   - Cập nhật [`customLooker.zip`](file:///D:/customLooker/customLooker.zip).
   - Deploy GCS `gs://analytics_merap/excelchart2/`.
   - Push commit mới lên GitHub: [https://github.com/duyvanda/customlooker.git](https://github.com/duyvanda/customlooker.git).

## 2. Danh sách file trong gói ZIP [`customLooker.zip`](file:///D:/customLooker/customLooker.zip)

- [`src/index.js`](file:///D:/customLooker/src/index.js): Mã nguồn bảng JS chỉ trích xuất đúng Dimension được chọn trong `Search Dimension`.
- [`downloader.html`](file:///D:/customLooker/downloader.html): Giao diện xuất Excel kèm chức năng copy tiêu chí bộ lọc chuẩn.
- [`index.css`](file:///D:/customLooker/index.css): Giao diện bảng.
- [`index.json`](file:///D:/customLooker/index.json): Schema Looker Studio.
- [`manifest.json`](file:///D:/customLooker/manifest.json): Khai báo tài nguyên Community Visualization ở chế độ `"devMode": true`.
- [`package.json`](file:///D:/customLooker/package.json): Cấu hình dependencies npm.
- [`webpack.config.js`](file:///D:/customLooker/webpack.config.js): Cấu hình đóng gói Webpack.
- [`index.bundle.js`](file:///D:/customLooker/index.bundle.js): File bundle tối ưu (~31.3 KB).
- [`agent.md`](file:///D:/customLooker/agent.md): Tài liệu toàn diện về toàn bộ quy tắc hoạt động, cấu hình, formatter và kiến trúc của biểu đồ.
- [`changelog/`](file:///D:/customLooker/changelog): Lịch sử thay đổi và nhật ký chi tiết của dự án.
