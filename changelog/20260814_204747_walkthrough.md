# Walkthrough: Custom Looker Studio Table Viz - Complete Crisp Modal & Crystal Clear Typography

## 1. Vấn đề gốc rễ & Các giải pháp đã triển khai

1. **Khắc phục triệt để hiện tượng Modal bị mờ (`image copy.png`):**
   - **Nguyên nhân:** Thuộc tính CSS `backdrop-filter: blur(3px)` kết hợp `animation: fadeIn` trên lớp `.modal-overlay` khi chạy bên trong môi trường `<iframe>` của trình duyệt Chromium (Chrome/Edge) sẽ kích hoạt chế độ GPU layer rasterization ở độ phân giải thấp (downscaled composite layer), dẫn đến toàn bộ nội dung hộp thoại Modal (chữ, bảng, input) bị mờ mịt, nhòe nét.
   - **Đã fix:**
     - Xóa bỏ hoàn toàn `backdrop-filter: blur()` và các hiệu ứng transform làm mất nét subpixel.
     - Sử dụng màu nền overlay chuẩn `background: rgba(15, 23, 42, 0.6)`.
     - Tăng cường độ tương phản chữ trong Modal lên màu đen tuyền `#000000` (`font-weight: 600 - 700`), viền khung xám đậm `#94a3b8`, nền trắng tinh khiết `#ffffff`.
     - Các ô input và dropdown hiển thị chữ đen đậm, sắc nét 100%.
2. **Khắc phục lỗi `TypeError: Cannot read properties of undefined (reading 'hierarchy')`:**
   - Chuẩn hóa cấu trúc schema `"data"` trong [`index.json`](file:///D:/customLooker/index.json) đúng đặc tả cấp 1 của Looker Studio Community Visualization SDK (chứa trực tiếp `DIMENSION` và `METRIC`).
3. **Gọn gàng Modal `⚙️ Cột Bảng & Màu Sắc`:**
   - Đã xóa bỏ cột `Màu cột (Color)` trong Tab 1 `📋 Cấu Hình Cột`.
   - Các nút dưới chân Modal được rút gọn chuẩn mực: **`Hủy`**, **`Lưu`**, **`🔄 Khôi phục mặc định`**.
4. **Đồng bộ chuẩn hóa tìm kiếm và so sánh điều kiện với `remove_accents()`:**
   - Tìm kiếm không dấu tiếng Việt và khớp quy tắc linh hoạt.
5. **Định dạng Ngày Tháng chuẩn Việt Nam `dd-mm-yyyy`:**
   - Tự động nhận diện chuỗi `YYYYMMDD` (8 chữ số của Looker Studio) và chuyển thành `01-01-2008`, `01-03-2011`, `20-04-1900`.
6. **Đóng gói dự án & Git:**
   - Cập nhật [`customLooker.zip`](file:///D:/customLooker/customLooker.zip).
   - Push lên GitHub [https://github.com/duyvanda/customlooker.git](https://github.com/duyvanda/customlooker.git).
   - Deploy GCS `gs://analytics_merap/excelchart2/`.

## 2. Danh sách file trong gói ZIP & Dự án

- [`index.css`](file:///D:/customLooker/index.css): Toàn bộ CSS siêu nét, loại bỏ backdrop-filter blur, màu đen đậm `#000000`, viền sắc nét, Modal Popup & Buttons.
- [`index.json`](file:///D:/customLooker/index.json): Khai báo Data Setup chuẩn cấu trúc cấp 1 (Dimensions, Metrics) và Style Panel.
- [`src/index.js`](file:///D:/customLooker/src/index.js): Toàn bộ logic Table Viz, Modal Tùy chỉnh cột gọn gàng, Nút Hủy và Lưu chuẩn xác.
- [`downloader.html`](file:///D:/customLooker/downloader.html): Giao diện tải file Excel, CSV & Copy JSON.
- [`manifest.json`](file:///D:/customLooker/manifest.json): Khai báo tài nguyên Community Visualization.
- [`package.json`](file:///D:/customLooker/package.json): Cấu hình dependencies npm.
- [`webpack.config.js`](file:///D:/customLooker/webpack.config.js): Cấu hình đóng gói Webpack.
- [`index.bundle.js`](file:///D:/customLooker/index.bundle.js): File bundle đã build sẵn để deploy (~42.0 KB).
- [`agent.md`](file:///D:/customLooker/agent.md): Tài liệu tổng quan kiến trúc, luồng hoạt động và hướng dẫn sử dụng.
