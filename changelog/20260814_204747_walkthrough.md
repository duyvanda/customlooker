# Walkthrough: Custom Looker Studio Table Viz - Admin Configurable Default Page Size

## 1. Vấn đề gốc rễ & Các giải pháp đã triển khai

1. **Lỗi iframe Sandbox (`Download is disallowed`):**
   - Đã giải quyết triệt để thông qua kiến trúc trang trung gian [`downloader.html`](file:///D:/customLooker/downloader.html) với giao diện tinh gọn, hỗ trợ xuất Excel (`.xlsx`), CSV (UTF-8 có BOM), và Copy JSON.
2. **Khắc phục lỗi file Excel rỗng:**
   - Sử dụng phương thức `XLSX.utils.aoa_to_sheet([headers, ...rows])` (ma trận 2 chiều) đảm bảo chính xác 100% tất cả dòng và cột theo cấu hình hiển thị thực tế.
3. **Hiển thị Skeleton Loading rõ ràng (Visible Skeleton):**
   - Nhúng CSS Animation Shimmer trực tiếp và thiết lập thời gian hiển thị 700ms mượt mà trước khi load bảng.
4. **Admin có thể thiết lập số dòng mặc định cho toàn bộ báo cáo (Admin Master Default Page Size):**
   - **Cấu hình trong Tab Style của Looker Studio:** Mục **"Số dòng mặc định mỗi trang"** trong tab **Style** bên phải của Looker Studio cung cấp đầy đủ các mức: `10`, `20`, `25`, `50`, `100`, `250`, `500`, `1000`, `Tất cả dòng (Không phân trang)`.
   - **Đồng bộ tự động:** Khi Admin chọn bất kỳ mức nào (ví dụ chọn `1000` hoặc `Tất cả`), bảng sẽ lập tức áp dụng mức này làm mặc định master cho tất cả người xem báo cáo khi mở dashboard hoặc F5 tải lại trang.
5. **Quy tắc Tô Màu & Gắn Badge Động (Dynamic Rules Engine):**
   - Xóa hoàn toàn hardcode màu.
   - Thêm tab `🎨 Quy Tắc Tô Màu & Badge Động` trong Modal `⚙️ Cột Bảng & Màu Sắc` cho phép người dùng tự do cấu hình quy tắc theo từ khóa, so sánh số cho bất kỳ bảng nào và lưu vào `localStorage`.
6. **Bộ tính năng Table Nâng cao:**
   - DOM Native Table, Sticky Header, Row Density (`compact`, `normal`, `relaxed`), Table Variants (`striped`, `bordered`, `default`), Font Size (11-15px).
   - Tự động sinh cột STT, Ngắt dòng, Căn lề tự động thông minh.
   - Sắp xếp tự nhiên (Natural Sort tiếng Việt, Số, Ngày tháng).
   - Tách biệt hoàn toàn `searchFields` khỏi bảng hiển thị.
7. **Đóng gói dự án & Git:**
   - Cập nhật [`customLooker.zip`](file:///D:/customLooker/customLooker.zip).
   - Push lên GitHub [https://github.com/duyvanda/customlooker.git](https://github.com/duyvanda/customlooker.git).
   - Deploy GCS `gs://analytics_merap/excelchart2/`.

## 2. Danh sách file trong gói ZIP & Dự án

- [`src/index.js`](file:///D:/customLooker/src/index.js): Toàn bộ logic Table Viz, Modal Tùy chỉnh cột, Dynamic Rules, Admin Master PageSize Sync, Formatter, Sort & Export.
- [`downloader.html`](file:///D:/customLooker/downloader.html): Giao diện tải file Excel, CSV & Copy JSON.
- [`index.css`](file:///D:/customLooker/index.css): Toàn bộ CSS giao diện Inter font, Modal Popup Tabs, Table Variants, Densities, Badges, Mono font & Scrollbar.
- [`index.json`](file:///D:/customLooker/index.json): Khai báo Data Setup và Style Panel (defaultPageSize, Density, Variant, Font Size, STT, Wrap, Search, Col Config).
- [`manifest.json`](file:///D:/customLooker/manifest.json): Khai báo tài nguyên Community Visualization.
- [`package.json`](file:///D:/customLooker/package.json): Cấu hình dependencies npm.
- [`webpack.config.js`](file:///D:/customLooker/webpack.config.js): Cấu hình đóng gói Webpack.
- [`index.bundle.js`](file:///D:/customLooker/index.bundle.js): File bundle đã build sẵn để deploy (~40.6 KB).
- [`agent.md`](file:///D:/customLooker/agent.md): Tài liệu tổng quan kiến trúc, luồng hoạt động và hướng dẫn sử dụng.
