# Walkthrough: Custom Looker Studio Table Viz - Streamlined Modal Layout & High-Contrast Typography

## 1. Vấn đề gốc rễ & Các giải pháp đã triển khai

1. **Gọn gàng Modal `⚙️ Cột Bảng & Màu Sắc` (`image.png`):**
   - Đã **xóa bỏ hoàn toàn cột `Màu cột (Color)`** trong Tab 1 **`📋 Cấu Hình Cột`** để tránh dư thừa và rối mắt, vì toàn bộ tính năng tô màu & gắn badge động chuyên sâu đã nằm trọn vẹn ở Tab 2 **`🎨 Quy Tắc Tô Màu & Badge Động`**.
   - Các nút dưới chân Modal đã được rút gọn chuẩn mực:
     - Nút **`Hủy`** (thay cho `Hủy bỏ`).
     - Nút **`Lưu`** (thay cho `Lưu & Áp Dụng ✓`).
     - Nút **`🔄 Khôi phục mặc định`**.
2. **Khắc phục triệt để hiện tượng chữ bảng bị mờ:**
   - Cập nhật màu chữ chính sang màu đen đậm chất lượng cao (`#0f172a` / `#1e293b`), tăng độ dày chữ (`font-weight: 450 - 600`), tiêu đề cột đậm nét (`font-weight: 700`).
   - Kích hoạt hệ thống font chữ chuẩn Native High-DPI (`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`) kèm cơ chế khử răng cưa mượt mà (`-webkit-font-smoothing: antialiased; -moz-osx-font-smoothing: grayscale; text-rendering: optimizeLegibility`).
   - Tăng độ tương phản của đường viền ô bảng (`border: 1px solid #cbd5e1` / `#e2e8f0`).
3. **Đồng bộ chuẩn hóa tìm kiếm và so sánh điều kiện với `remove_accents()`:**
   - Tìm kiếm không dấu tiếng Việt và khớp quy tắc linh hoạt.
4. **Định dạng Ngày Tháng chuẩn Việt Nam `dd-mm-yyyy`:**
   - Tự động nhận diện chuỗi `YYYYMMDD` (8 chữ số của Looker Studio) và chuyển thành `01-01-2008`, `01-03-2011`, `20-04-1900`.
5. **Đóng gói dự án & Git:**
   - Cập nhật [`customLooker.zip`](file:///D:/customLooker/customLooker.zip).
   - Push lên GitHub [https://github.com/duyvanda/customlooker.git](https://github.com/duyvanda/customlooker.git).
   - Deploy GCS `gs://analytics_merap/excelchart2/`.

## 2. Danh sách file trong gói ZIP & Dự án

- [`src/index.js`](file:///D:/customLooker/src/index.js): Toàn bộ logic Table Viz, Modal Tùy chỉnh cột gọn gàng không còn cột màu thừa, Nút Hủy và Lưu chuẩn xác, Độ tương phản cao.
- [`downloader.html`](file:///D:/customLooker/downloader.html): Giao diện tải file Excel, CSV & Copy JSON.
- [`index.css`](file:///D:/customLooker/index.css): Toàn bộ CSS siêu nét, High-DPI font rendering, màu đen đậm `#0f172a`, viền sắc nét, Modal Popup Tabs & Buttons.
- [`index.json`](file:///D:/customLooker/index.json): Khai báo Data Setup (Dimensions, Metrics, searchFields) và Style Panel.
- [`manifest.json`](file:///D:/customLooker/manifest.json): Khai báo tài nguyên Community Visualization.
- [`package.json`](file:///D:/customLooker/package.json): Cấu hình dependencies npm.
- [`webpack.config.js`](file:///D:/customLooker/webpack.config.js): Cấu hình đóng gói Webpack.
- [`index.bundle.js`](file:///D:/customLooker/index.bundle.js): File bundle đã build sẵn để deploy (~42.4 KB).
- [`agent.md`](file:///D:/customLooker/agent.md): Tài liệu tổng quan kiến trúc, luồng hoạt động và hướng dẫn sử dụng.
