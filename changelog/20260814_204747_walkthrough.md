# Walkthrough: Custom Looker Studio Table Viz - Dimension-Only Freeze Columns

## 1. Tóm tắt các thay đổi vừa hoàn thiện

1. **Cố Định Cột (Freeze Columns) chỉ áp dụng cho Dimension:**
   - Đã loại bỏ ô `freezeMetrics`, chỉ giữ lại duy nhất **`📌 Cố định Dimension (Freeze Columns)`** trong tab Setup (Data).
   - Đảm bảo đúng chuẩn hành vi bảng dữ liệu phân tích: Chỉ các cột Dimension (thứ nguyên, danh mục, phân loại) đứng bên trái được ghim cố định khi cuộn ngang.
2. **Cập nhật gói ZIP & Triển khai:**
   - Cập nhật [`customLooker.zip`](file:///D:/customLooker/customLooker.zip).
   - Deploy GCS `gs://analytics_merap/excelchart2/`.
   - Push commit mới lên GitHub: [https://github.com/duyvanda/customlooker.git](https://github.com/duyvanda/customlooker.git).

---

## 2. Danh sách file trong gói ZIP [`customLooker.zip`](file:///D:/customLooker/customLooker.zip)

- [`index.json`](file:///D:/customLooker/index.json): Schema Looker Studio chỉ chứa `freezeDimensions` trong Setup.
- [`src/index.js`](file:///D:/customLooker/src/index.js): Mã nguồn bảng JS tối ưu hóa tính toán Freeze cho Dimension.
- [`index.css`](file:///D:/customLooker/index.css): Giao diện bảng và các kiểu sticky header/cells.
- [`downloader.html`](file:///D:/customLooker/downloader.html): Giao diện tải file Excel `.xlsx`, `.csv` & Copy JSON.
- [`manifest.json`](file:///D:/customLooker/manifest.json): Khai báo tài nguyên Community Visualization ở chế độ `"devMode": true`.
- [`package.json`](file:///D:/customLooker/package.json): Cấu hình dependencies npm.
- [`webpack.config.js`](file:///D:/customLooker/webpack.config.js): Cấu hình đóng gói Webpack.
- [`index.bundle.js`](file:///D:/customLooker/index.bundle.js): File bundle tối ưu (~30.2 KB).
- [`agent.md`](file:///D:/customLooker/agent.md): Tài liệu toàn diện về toàn bộ quy tắc hoạt động, cấu hình, formatter và kiến trúc của biểu đồ.
- [`changelog/`](file:///D:/customLooker/changelog): Lịch sử thay đổi và nhật ký chi tiết của dự án.
