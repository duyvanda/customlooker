# Walkthrough: Custom Looker Studio Table Viz - Pure Excel (.xlsx) Export

## 1. Tóm tắt các thay đổi vừa hoàn thiện

1. **Bỏ chức năng Copy JSON:**
   - Đã loại bỏ hoàn toàn nút và logic Copy JSON khỏi trang tải file [`downloader.html`](file:///D:/customLooker/downloader.html).
   - Giao diện tải file giờ đây tối giản 100%, tập trung hoàn toàn vào việc tự động tải ngay **File Excel (`.xlsx`)** chuẩn chỉnh với đầy đủ format, độ rộng cột tự động và bảo toàn số 0 ở đầu.
2. **Cập nhật gói ZIP & Triển khai:**
   - Cập nhật [`customLooker.zip`](file:///D:/customLooker/customLooker.zip).
   - Deploy GCS `gs://analytics_merap/excelchart2/`.
   - Push commit mới lên GitHub: [https://github.com/duyvanda/customlooker.git](https://github.com/duyvanda/customlooker.git).

---

## 2. Danh sách file trong gói ZIP [`customLooker.zip`](file:///D:/customLooker/customLooker.zip)

- [`downloader.html`](file:///D:/customLooker/downloader.html): Giao diện và logic xuất file Excel `.xlsx` chuyên biệt, siêu gọn nhẹ.
- [`src/index.js`](file:///D:/customLooker/src/index.js): Mã nguồn bảng JS.
- [`index.json`](file:///D:/customLooker/index.json): Schema Looker Studio.
- [`index.css`](file:///D:/customLooker/index.css): Giao diện bảng và các kiểu sticky header/cells.
- [`manifest.json`](file:///D:/customLooker/manifest.json): Khai báo tài nguyên Community Visualization ở chế độ `"devMode": true`.
- [`package.json`](file:///D:/customLooker/package.json): Cấu hình dependencies npm.
- [`webpack.config.js`](file:///D:/customLooker/webpack.config.js): Cấu hình đóng gói Webpack.
- [`index.bundle.js`](file:///D:/customLooker/index.bundle.js): File bundle tối ưu (~30.4 KB).
- [`agent.md`](file:///D:/customLooker/agent.md): Tài liệu toàn diện về toàn bộ quy tắc hoạt động, cấu hình, formatter và kiến trúc của biểu đồ.
- [`changelog/`](file:///D:/customLooker/changelog): Lịch sử thay đổi và nhật ký chi tiết của dự án.

---

## 3. Trạng thái triển khai

- **Google Cloud Storage:** Đã upload toàn bộ file với quyền `public-read` lên `gs://analytics_merap/excelchart2/`.
- **GitHub Repository:** Đã đẩy toàn bộ mã nguồn lên [https://github.com/duyvanda/customlooker.git](https://github.com/duyvanda/customlooker.git) (branch `main`).
