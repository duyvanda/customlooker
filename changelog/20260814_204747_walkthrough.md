# Walkthrough: Custom Looker Studio Table Viz - Multi-Layer Persistence & Cache Busting

## 1. Vấn đề gốc rễ & Các giải pháp đã triển khai

1. **Nguyên nhân hình ảnh chụp `image copy 4.png` hiển thị Modal cũ & Không lưu:**
   - Trình duyệt Chrome lưu cache file JavaScript bundle cũ của Looker Studio iframe (`index.bundle.js` phiên bản trước khi thêm cột `🔍 Tìm` và `Sắp xếp (Sort)`).
   - Trong môi trường Iframe sandbox của Google Looker Studio (`*.googleusercontent.com`), cơ chế Third-Party Storage Partitioning của Chrome có thể cô lập `localStorage` nếu chưa hỗ trợ đa tầng.
2. **Nâng cấp Hệ thống Lưu trữ Đa tầng (Multi-layer Persistence):**
   - Đã xây dựng bộ 3 tầng lưu trữ dự phòng:
     - **Tầng 1:** `window.localStorage` (lưu dài hạn trên trình duyệt).
     - **Tầng 2:** `window.sessionStorage` (lưu theo phiên làm việc).
     - **Tầng 3:** `window.name` (bảo toàn cấu hình kể cả khi iframe bị F5 reload lại).
   - Đảm bảo khi bạn ẩn cột, đổi tên nhãn, chọn định dạng, chọn cột sort hoặc chọn cột tìm kiếm và bấm **`Lưu`**, cấu hình sẽ **tồn tại vĩnh viễn 100% khi bấm F5 reload báo cáo**.
3. **Đóng gói dự án & Git:**
   - Cập nhật [`customLooker.zip`](file:///D:/customLooker/customLooker.zip).
   - Push lên GitHub [https://github.com/duyvanda/customlooker.git](https://github.com/duyvanda/customlooker.git).
   - Deploy GCS `gs://analytics_merap/excelchart2/` kèm header `Cache-Control: no-cache, no-store, must-revalidate`.

## 2. Danh sách file trong gói ZIP & Dự án

- [`src/index.js`](file:///D:/customLooker/src/index.js): Hệ thống lưu trữ đa tầng Multi-layer persistence, Checkbox `🔍 Tìm`, Cột `Sắp xếp (Sort)`, Phân trang 10 cột, 3-state sorting, Formatter.
- [`downloader.html`](file:///D:/customLooker/downloader.html): Giao diện tải file Excel, CSV & Copy JSON.
- [`index.css`](file:///D:/customLooker/index.css): Căn trên cho modal overlay (`flex-start`), Modal pagination styles, màu đen đậm `#000000`.
- [`index.json`](file:///D:/customLooker/index.json): Khai báo Data Setup chuẩn quốc tế (`Dimension`, `Metric`) và Style Panel.
- [`manifest.json`](file:///D:/customLooker/manifest.json): Khai báo tài nguyên Community Visualization ở chế độ Production.
- [`package.json`](file:///D:/customLooker/package.json): Cấu hình dependencies npm.
- [`webpack.config.js`](file:///D:/customLooker/webpack.config.js): Cấu hình đóng gói Webpack.
- [`index.bundle.js`](file:///D:/customLooker/index.bundle.js): File bundle đã build sẵn để deploy (~46.3 KB).
- [`agent.md`](file:///D:/customLooker/agent.md): Tài liệu toàn diện về toàn bộ quy tắc hoạt động, cấu hình, formatter và kiến trúc của biểu đồ.
