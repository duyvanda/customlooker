# Walkthrough: Custom Looker Studio Table Viz - Production Deployment (devMode: false) & Complete Agent Rulebook

## 1. Tóm tắt các thay đổi vừa hoàn thiện

1. **Chuyển `devMode` sang `false` cho Production Release:**
   - Trong [`manifest.json`](file:///D:/customLooker/manifest.json), đã cập nhật `"devMode": false` phục vụ triển khai chính thức trên Looker Studio.
2. **Cập nhật toàn diện tài liệu [`agent.md`](file:///D:/customLooker/agent.md):**
   - Bổ sung và hệ thống hóa 100% quy tắc dự án:
     - **Kiến trúc Setup-Driven Native:** Bố cục các trường trong Setup (`Data`, `Dimension`, `Metric`, `Freeze Dimension`, `Search Dimension`, `Sort Dimension 1-3`, `Sort Metric 1-3`, `Conditional Dimension 1-3`, `Conditional Metric 1-3`).
     - **Bố cục Tab Style:** `tableAppearance` (Giao diện Bảng) nằm ở đầu, kế tiếp là `sortingSection`, `searchSection`, `rule1Section`–`rule3Section`.
     - **Quy tắc Cố Định Cột (Sticky Freeze Columns):** Chỉ cho phép cố định Dimension, tự động tính toán pixel `left` offset và tạo hiệu ứng ranh giới đổ bóng `.frozen-column-last`.
     - **Quy tắc Xuất File Excel:** Bảo toàn số 0 ở đầu cho số điện thoại/mã định danh bằng cell type Text (`t: 's'`, format `@`), tự động mở rộng độ rộng cột.
     - **Quy tắc Date Range:** Giữ nguyên 100% đối tượng `dateRanges.DEFAULT` từ Looker Studio API.
     - **Quy trình Build & Deploy:** Đầy đủ các câu lệnh Webpack, GCS Bucket `gs://analytics_merap/excelchart2/`, đóng gói zip và commit Git tiếng Việt.
3. **Cập nhật gói ZIP & Triển khai:**
   - Cập nhật [`customLooker.zip`](file:///D:/customLooker/customLooker.zip).
   - Deploy GCS `gs://analytics_merap/excelchart2/` (quyền `public-read`, `no-cache`).
   - Push commit mới lên GitHub: [https://github.com/duyvanda/customlooker.git](https://github.com/duyvanda/customlooker.git).
