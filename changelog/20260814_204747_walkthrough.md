# Walkthrough: Custom Looker Studio Table Viz - Full Package Update

## 1. Tóm tắt các nâng cấp và cập nhật mới nhất

1. **Storage Bridge cho Lưu trữ Vĩnh viễn (Permanent Persistence):**
   - Tích hợp [`storage_bridge.html`](file:///D:/customLooker/storage_bridge.html) chạy ngầm trên `https://storage.googleapis.com`.
   - Khắc phục hoàn toàn hiện tượng Looker Studio đổi subdomain ngẫu nhiên sau khi F5 làm mất trạng thái ẩn/hiện cột, sort, hoặc tìm kiếm.
2. **Cấu hình Cột & Tìm kiếm thông minh:**
   - Cột **`🔍 Tìm`** mặc định **Uncheck All** (khi chưa chọn cột nào sẽ tìm kiếm toàn bộ; khi tích chọn sẽ chỉ tìm kiếm trên đúng các cột được chọn).
   - Cột **`Sắp xếp (Sort)`** cho phép đặt kiểu sort mặc định (None, ASC, DESC) trực tiếp trong Modal.
   - Sắp xếp nhanh 3 nấc (`▲` / `▼` / `↕`) trực tiếp khi click chuột vào tiêu đề cột trên bảng.
   - Modal căn trên cùng (`flex-start`) và phân trang **10 cột/trang**.
3. **Cập nhật gói ZIP & Triển khai:**
   - Đã tạo mới và cập nhật file nén [`customLooker.zip`](file:///D:/customLooker/customLooker.zip) chứa đầy đủ các file mã nguồn và build mới nhất.
   - Deploy toàn bộ lên Google Cloud Storage: `gs://analytics_merap/excelchart2/`.
   - Push commit mới lên GitHub: [https://github.com/duyvanda/customlooker.git](https://github.com/duyvanda/customlooker.git).

## 2. Danh sách file trong gói ZIP [`customLooker.zip`](file:///D:/customLooker/customLooker.zip)

- [`src/index.js`](file:///D:/customLooker/src/index.js): Client logic tích hợp Storage Bridge, Multi-layer persistence, Checkbox `🔍 Tìm`, Cột `Sắp xếp (Sort)`, Phân trang 10 cột, 3-state sorting, Formatter.
- [`storage_bridge.html`](file:///D:/customLooker/storage_bridge.html): Cầu nối lưu trữ dữ liệu vĩnh viễn trên domain cố định `storage.googleapis.com`.
- [`downloader.html`](file:///D:/customLooker/downloader.html): Giao diện tải file Excel, CSV & Copy JSON.
- [`index.css`](file:///D:/customLooker/index.css): Căn trên cho modal overlay (`flex-start`), Modal pagination styles, màu đen đậm `#000000`.
- [`index.json`](file:///D:/customLooker/index.json): Khai báo Data Setup chuẩn quốc tế (`Dimension`, `Metric`) và Style Panel.
- [`manifest.json`](file:///D:/customLooker/manifest.json): Khai báo tài nguyên Community Visualization ở chế độ `"devMode": true`.
- [`package.json`](file:///D:/customLooker/package.json): Cấu hình dependencies npm.
- [`webpack.config.js`](file:///D:/customLooker/webpack.config.js): Cấu hình đóng gói Webpack.
- [`index.bundle.js`](file:///D:/customLooker/index.bundle.js): File bundle đã build sẵn để deploy (~47.7 KB).
- [`agent.md`](file:///D:/customLooker/agent.md): Tài liệu toàn diện về toàn bộ quy tắc hoạt động, cấu hình, formatter và kiến trúc của biểu đồ.
- [`changelog/`](file:///D:/customLooker/changelog): Lịch sử thay đổi và nhật ký chi tiết của dự án.
