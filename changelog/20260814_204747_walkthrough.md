# Walkthrough: Custom Looker Studio Table Viz - Native Setup & Style Architecture

## 1. Tóm tắt toàn bộ kiến trúc chuẩn theo `feedback.md`

1. **Loại bỏ 100% Persistence Custom:**
   - Xóa bỏ toàn bộ `localStorage`, `sessionStorage`, `storage_bridge.html`, `window.name` và các logic lưu trữ thủ công.
   - **Looker Setup + Style là nguồn chân lý duy nhất (Single Source of Truth)** được Google Looker Studio lưu trữ vĩnh viễn cùng báo cáo và bảo toàn 100% qua mọi lần F5.
2. **Cấu trúc Tab Setup (Data):**
   - Quản lý danh sách Dimension & Metric, thứ tự cột, số dòng tối đa và đổi tên cột (Rename field trực tiếp từ giao diện Looker Studio native).
3. **Cố định `baseColumns` (Slot `c0`..`c29`):**
   - Nhận diện cột theo slot cố định `c0`, `c1`, `c2`... giúp việc ẩn/hiện cột tạm thời ở runtime không bao giờ làm lệch các cấu hình Sort và Conditional Formatting.
4. **Cấu trúc Tab Style (`index.json`):**
   - **Sắp xếp (Sorting):** Chọn cột sắp xếp mặc định (`Column 1`–`Column 30`), Chiều sort (`Ascending` / `Descending`), Cho phép click header sort.
   - **Tìm kiếm (Search):** Bật/tắt ô tìm kiếm, Từ khóa mặc định (`defaultSearchText`), Phạm vi quét (`Visible columns`, `All columns`, `Column 1`..`Column 30`), Chế độ khớp (`Contains`, `Equals`, `Starts with`), Phân biệt hoa/thường.
   - **Tô Màu & Badge (Rules 1–5):** 5 quy tắc cố định với đầy đủ các toán tử so sánh (chứa, bằng, khác, bắt đầu, kết thúc, lớn hơn, nhỏ hơn, trong khoảng, số âm/dương, rỗng/không rỗng) và các kiểu badge/màu chữ.
   - **Giao diện Bảng:** Mật độ dòng (Compact/Normal/Relaxed), Kiểu bảng (Striped/Bordered/Default), Cỡ chữ (11px–16px), Cột STT, Text Wrap, Bật/tắt Popup Ẩn/Hiện cột runtime.
5. **Runtime Memory State:**
   - Chỉ lưu trạng thái tương tác tạm thời của người xem (`currentPage`, `searchText`, `sortOverride` 3 nấc: Asc -> Desc -> Default, `hiddenColumns`).
   - Tự động khôi phục về giá trị mặc định của Style khi F5.
6. **Đóng gói & Triển khai:**
   - File bundle cực nhẹ: **27.7 KiB** (giảm 42%).
   - Cập nhật [`customLooker.zip`](file:///D:/customLooker/customLooker.zip).
   - Deploy GCS: `gs://analytics_merap/excelchart2/`.
   - Push commit GitHub: [https://github.com/duyvanda/customlooker.git](https://github.com/duyvanda/customlooker.git).
