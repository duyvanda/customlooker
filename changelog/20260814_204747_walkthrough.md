# Walkthrough: Custom Looker Studio Table Viz - Storage Bridge for Permanent Cross-Origin Persistence

## 1. Vấn đề gốc rễ & Các giải pháp đã triển khai

1. **Nguyên nhân cốt lõi khiến F5 bị mất cấu hình ẩn cột / tick tìm kiếm:**
   - Khi bạn bấm **F5 (Tải lại trang)** trên Looker Studio, Google sẽ tự động sinh ra một **tên miền con (subdomain) Sandbox ngẫu nhiên mới** cho Iframe biểu đồ (ví dụ: `https://n-random1.googleusercontent.com` -> `https://n-random2.googleusercontent.com`).
   - Do chính sách bảo mật Same-Origin Policy của trình duyệt, `localStorage` và `sessionStorage` của `random1` bị chặn hoàn toàn và không thể đọc được bởi `random2`.
2. **Giải pháp kiến trúc Đột phá: Storage Bridge trên `storage.googleapis.com`:**
   - Tạo file cầu nối [`storage_bridge.html`](file:///D:/customLooker/storage_bridge.html) chạy ngầm trên **domain cố định duy nhất**: `https://storage.googleapis.com/analytics_merap/excelchart2/storage_bridge.html`.
   - Biểu đồ nhúng một Iframe ẩn kết nối đến Storage Bridge qua cơ chế bảo mật `postMessage`.
   - **Kết quả:** Vì `storage.googleapis.com` là tên miền cố định bất biến, mọi cấu hình (Ẩn/Hiện cột, Cột tìm kiếm `🔍 Tìm`, Sắp xếp `Sort`, Định dạng `Format`, Thứ tự cột, Quy tắc màu `Badge`) sẽ **được lưu trữ vĩnh viễn 100%, không bao giờ bị mất sau bất kỳ lần F5 hay tắt mở lại trình duyệt nào!**
3. **Đóng gói dự án & Git:**
   - Cập nhật [`customLooker.zip`](file:///D:/customLooker/customLooker.zip).
   - Push lên GitHub [https://github.com/duyvanda/customlooker.git](https://github.com/duyvanda/customlooker.git).
   - Deploy GCS `gs://analytics_merap/excelchart2/`.

## 2. Danh sách file trong gói ZIP & Dự án

- [`storage_bridge.html`](file:///D:/customLooker/storage_bridge.html): Cầu nối lưu trữ dữ liệu vĩnh viễn trên domain cố định `storage.googleapis.com`.
- [`src/index.js`](file:///D:/customLooker/src/index.js): Tích hợp Storage Bridge Client, Checkbox `🔍 Tìm`, Cột `Sắp xếp (Sort)`, Phân trang 10 cột, 3-state sorting, Formatter.
- [`manifest.json`](file:///D:/customLooker/manifest.json): Khai báo `"devMode": true` để Looker Studio luôn nạp code mới từ GCS.
- [`downloader.html`](file:///D:/customLooker/downloader.html): Giao diện tải file Excel, CSV & Copy JSON.
- [`index.css`](file:///D:/customLooker/index.css): Căn trên cho modal overlay (`flex-start`), Modal pagination styles, màu đen đậm `#000000`.
- [`index.json`](file:///D:/customLooker/index.json): Khai báo Data Setup chuẩn quốc tế (`Dimension`, `Metric`) và Style Panel.
- [`package.json`](file:///D:/customLooker/package.json): Cấu hình dependencies npm.
- [`webpack.config.js`](file:///D:/customLooker/webpack.config.js): Cấu hình đóng gói Webpack.
- [`index.bundle.js`](file:///D:/customLooker/index.bundle.js): File bundle đã build sẵn để deploy (~47.7 KB).
- [`agent.md`](file:///D:/customLooker/agent.md): Tài liệu toàn diện về toàn bộ quy tắc hoạt động, cấu hình, formatter và kiến trúc của biểu đồ.
