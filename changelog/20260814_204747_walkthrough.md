# Walkthrough: Custom Looker Studio Table Viz - Extract & Copy Filter Parameters (Criteria)

## 1. Tóm tắt các thay đổi vừa hoàn thiện

1. **Chuẩn hóa tính năng Trích xuất & Copy Giá Trị Bộ Lọc (Filter Parameters/Criteria):**
   - **Mục đích:** Khi người dùng lọc trên Looker Studio (chọn khoảng ngày Date Range, chọn các giá trị trong Dropdown Filter như `hovatenfullname=ABC,XYZ`), hệ thống sẽ tự động tổng hợp chính xác các giá trị điều kiện lọc này thay vì dump toàn bộ bảng dữ liệu.
   - **Cơ chế hoạt động:**
     - Tự động trích xuất `startDate`, `endDate` từ Date Range Control của Looker Studio.
     - Tự động trích xuất các giá trị Dimension đang được lọc (ví dụ: `hovatenfullname: ["ABC", "XYZ"]`, `Khối: ["Commercial/ Front"]`).
     - Tự động lấy từ khóa tìm kiếm `searchKeyword` nếu có.
   - **Giao diện trang Xuất Excel:**
     - **Nút `📋 Copy JSON Bộ Lọc`:** Sao chép cấu trúc JSON:
       ```json
       {
         "dateRange": {
           "startDate": "2026-08-01",
           "endDate": "2026-08-31"
         },
         "dimensions": {
           "hovatenfullname": ["ABC", "XYZ"]
         }
       }
       ```
     - **Nút `📝 Copy Text Bộ Lọc`:** Sao chép dạng chuỗi gọn nhẹ:
       `startdate=2026-08-01 and enddate=2026-08-31 and hovatenfullname=ABC,XYZ`

## 2. Danh sách file trong gói ZIP [`customLooker.zip`](file:///D:/customLooker/customLooker.zip)

- [`downloader.html`](file:///D:/customLooker/downloader.html): Giao diện xuất Excel kèm chức năng copy tiêu chí bộ lọc dạng JSON và dạng Text.
