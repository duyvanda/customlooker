# Walkthrough: Custom Looker Studio Table Viz - Edit Mode Component Selection & Auto-Focus

## 1. Vấn đề gốc rễ & Các giải pháp đã triển khai

1. **Cơ chế chọn Component trong Edit Mode của Looker Studio:**
   - **Hiện tượng trên hình (`image copy 11.png`):** Báo cáo đang ở chế độ xem (View Mode) hoặc chưa được chọn tiêu điểm iframe, dẫn tới Looker Studio chỉ hiện icon cây bút ✏️ ở góc trên bên phải mà không mở thanh cấu hình bên phải.
   - **Đã nâng cấp:**
     - Tích hợp sự kiện lắng nghe `window.focus()` trên cả `click` và `mousedown` bên trong visualization. Khi người dùng nhấp vào bất kỳ vùng nào của biểu đồ trong **Edit Mode**, iframe sẽ lập tức báo focus về cho trang cha Looker Studio để tự động chọn component và mở thanh thuộc tính **Setup** / **Style** ở bên phải.
2. **Khắc phục triệt để lỗi `COMMUNITY_VIZ_JS_ERROR`:**
   - Đã bọc an toàn toàn bộ các hàm render, kiểm tra kiểu chuỗi, null-safety cho toàn bộ cấu hình cột và bảo vệ an toàn `localStorage`.
3. **Đồng bộ chuẩn hóa tìm kiếm và so sánh điều kiện với `remove_accents()` từ [`D:\django_apps\rest\frontend1\src\utils\string.js`](file:///D:/django_apps/rest/frontend1/src/utils/string.js):**
   - Tìm kiếm không dấu tiếng Việt và khớp quy tắc linh hoạt.
4. **Định dạng Ngày Tháng chuẩn Việt Nam `dd-mm-yyyy`:**
   - Tự động nhận diện chuỗi `YYYYMMDD` (8 chữ số của Looker Studio) và chuyển thành `01-01-2008`, `01-03-2011`, `20-04-1900`.
5. **Bộ Quy Tắc Điều Kiện Động Toàn Diện trong Modal `⚙️ Cột Bảng & Màu Sắc`:**
   - Quản lý 100% trực quan với đầy đủ toán tử `Chứa từ khóa (Contains)`, `Bằng chính xác (=)`, `Lớn hơn (>)`, `Nhỏ hơn (<)`, `>=`, `<=`, `Số dương (>=0)`, `Số âm (<0)`.
6. **Đóng gói dự án & Git:**
   - Cập nhật [`customLooker.zip`](file:///D:/customLooker/customLooker.zip).
   - Push lên GitHub [https://github.com/duyvanda/customlooker.git](https://github.com/duyvanda/customlooker.git).
   - Deploy GCS `gs://analytics_merap/excelchart2/`.

## 2. Danh sách file trong gói ZIP & Dự án

- [`src/index.js`](file:///D:/customLooker/src/index.js): Toàn bộ logic Table Viz, Modal Tùy chỉnh cột, Auto-focus component cho Edit Mode, Hàm bỏ dấu tiếng Việt `remove_accents()`, Bộ nhận diện Date/DateTime Looker Studio, Full Dynamic Condition Rules Engine, Formatter, Sort & Export.
- [`downloader.html`](file:///D:/customLooker/downloader.html): Giao diện tải file Excel, CSV & Copy JSON.
- [`index.css`](file:///D:/customLooker/index.css): Toàn bộ CSS giao diện Inter font, Modal Popup Tabs, Table Variants, Densities, Badges, Mono font & Scrollbar.
- [`index.json`](file:///D:/customLooker/index.json): Khai báo Data Setup (Dimensions, Metrics, searchFields) và Style Panel (defaultPageSize, Density, Variant, Font Size, STT, Wrap, Search, Col Config).
- [`manifest.json`](file:///D:/customLooker/manifest.json): Khai báo tài nguyên Community Visualization.
- [`package.json`](file:///D:/customLooker/package.json): Cấu hình dependencies npm.
- [`webpack.config.js`](file:///D:/customLooker/webpack.config.js): Cấu hình đóng gói Webpack.
- [`index.bundle.js`](file:///D:/customLooker/index.bundle.js): File bundle đã build sẵn để deploy (~44.0 KB).
- [`agent.md`](file:///D:/customLooker/agent.md): Tài liệu tổng quan kiến trúc, luồng hoạt động và hướng dẫn sử dụng.
