# Walkthrough: Custom Looker Studio Table Viz - Text Type Coercion & Modal Reset Fixes

## 1. Vấn đề gốc rễ & Các giải pháp đã triển khai

1. **Lỗi chuỗi Text chứa số bị ép kiểu nhầm thành số (ví dụ: `view_theo_doi_2026` biến thành `2.026`):**
   - **Nguyên nhân:** Hàm `formatTableCell` cũ dùng biểu thức `str.replace(/[^0-9.-]/g, '')` trích xuất các chữ số trong chuỗi chữ rồi đưa qua `toLocaleString('vi-VN')`, biến các chuỗi text như tên bảng/tên file `view_..._2026` thành số `2026` (`2.026`).
   - **Giải pháp:** Sử dụng hàm kiểm tra chặt chẽ `isNumericValue(val)` với biểu thức regex `/^-?\d+(\.\d+)?$/`. Chỉ những ô có giá trị hoàn toàn là số thực sự mới được format kiểu số; các chuỗi chữ/mã văn bản được giữ nguyên 100% định dạng ban đầu.
2. **Khắc phục lỗi nút "Khôi phục mặc định" trong Modal Tùy chỉnh cột:**
   - **Nguyên nhân:** Lệnh `window.confirm()` bị chặn trong môi trường sandboxed iframe của Looker Studio khiến hành động khôi phục không được thực thi; đồng thời `userColumnConfigs` không được reset hoàn toàn khi dọn `localStorage`.
   - **Giải pháp:** Bỏ `confirm()`, trực tiếp xóa `localStorage`, làm sạch danh sách cột trùng lặp cũ và gọi ngay `renderTable()` để tái tạo giao diện cột mặc định ban đầu.
3. **Bộ tính năng Table Nâng cao:**
   - DOM Native Table, Sticky Header, Row Density (`compact`, `normal`, `relaxed`), Table Variants (`striped`, `bordered`, `default`), Font Size (11-15px).
   - Tự động sinh cột STT, Ngắt dòng, Căn lề tự động thông minh.
   - Sắp xếp tự nhiên (Natural Sort tiếng Việt, Số, Ngày tháng).
   - Định dạng cột và tô màu có điều kiện.
   - Modal Tùy chỉnh cột (`⚙️ Cột Bảng`) lưu `localStorage`.
4. **Đóng gói dự án & Git:**
   - Cập nhật [`customLooker.zip`](file:///D:/customLooker/customLooker.zip).
   - Push lên GitHub [https://github.com/duyvanda/customlooker.git](https://github.com/duyvanda/customlooker.git).
