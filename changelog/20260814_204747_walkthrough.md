# Walkthrough: Custom Looker Studio Table Viz - Freeze Dimension Precision & Excel Only Export

## 1. Tóm tắt các thay đổi vừa hoàn thiện

1. **Khắc phục lỗi nhận diện Cột Freeze Dimension (`image.png`):**
   - **Nguyên nhân:** Looker Studio DSCC gán `field.id` nội bộ khác nhau khi cùng 1 trường dữ liệu được kéo thả vào 2 vị trí khác nhau (`Dimension` vs `Freeze Dimension`). Việc so sánh đơn thuần bằng `f.id` khiến hệ thống không khớp được cột `Khối`, dẫn đến việc chỉ ghim mỗi cột `STT` và đặt đường viền đổ bóng nhầm lên `STT`.
   - **Giải pháp:**
     - Chuẩn hóa hàm tìm kiếm cột theo cả `field.name` và `field.id`.
     - Cột `Khối` (hoặc bất kỳ Dimension nào được chọn trong `Freeze Dimension`) được nhận diện chính xác 100%.
     - Khi cuộn ngang: Cột `STT` (`left: 0`) và cột `Khối` (`left: 44px`) được ghim cố định mượt mà cùng nhau.
     - Đường viền và hiệu ứng đổ bóng phân cách (`frozen-column-last`) được gắn chính xác lên cột freeze cuối cùng (`Khối`).
2. **Bỏ chức năng xuất CSV:**
   - Đã loại bỏ hoàn toàn nút và logic xuất file CSV trong [`downloader.html`](file:///D:/customLooker/downloader.html).
   - Tập trung vào tính năng **Xuất File Excel (.xlsx)** hoàn hảo và **Copy JSON**.
3. **Cập nhật gói ZIP & Triển khai:**
   - Cập nhật [`customLooker.zip`](file:///D:/customLooker/customLooker.zip).
   - Deploy GCS `gs://analytics_merap/excelchart2/`.
   - Push commit mới lên GitHub: [https://github.com/duyvanda/customlooker.git](https://github.com/duyvanda/customlooker.git).

## 2. Danh sách file trong gói ZIP [`customLooker.zip`](file:///D:/customLooker/customLooker.zip)

- [`src/index.js`](file:///D:/customLooker/src/index.js): Mã nguồn bảng JS khớp chính xác cột Freeze Dimension theo tên field và tính toán offset sticky.
- [`downloader.html`](file:///D:/customLooker/downloader.html): Giao diện xuất file Excel `.xlsx` chuẩn và Copy JSON (đã bỏ CSV).
- [`index.json`](file:///D:/customLooker/index.json): Schema Looker Studio.
- [`index.css`](file:///D:/customLooker/index.css): Giao diện bảng và các kiểu sticky header/cells.
- [`manifest.json`](file:///D:/customLooker/manifest.json): Khai báo tài nguyên Community Visualization ở chế độ `"devMode": true`.
- [`package.json`](file:///D:/customLooker/package.json): Cấu hình dependencies npm.
- [`webpack.config.js`](file:///D:/customLooker/webpack.config.js): Cấu hình đóng gói Webpack.
- [`index.bundle.js`](file:///D:/customLooker/index.bundle.js): File bundle tối ưu (~30.4 KB).
- [`agent.md`](file:///D:/customLooker/agent.md): Tài liệu toàn diện về toàn bộ quy tắc hoạt động, cấu hình, formatter và kiến trúc của biểu đồ.
- [`changelog/`](file:///D:/customLooker/changelog): Lịch sử thay đổi và nhật ký chi tiết của dự án.
