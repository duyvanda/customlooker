# Walkthrough: Custom Looker Studio Table Viz - Full Enterprise Feature Suite (Feedback 3)

## 1. Vấn đề gốc rễ & Các giải pháp đã triển khai

1. **Lỗi iframe Sandbox (`Download is disallowed`):**
   - Đã giải quyết triệt để thông qua kiến trúc trang trung gian [`downloader.html`](file:///D:/customLooker/downloader.html) với giao diện tinh gọn, hỗ trợ xuất Excel (`.xlsx`), CSV (UTF-8 có BOM), và Copy JSON.
2. **Khắc phục lỗi file Excel rỗng:**
   - Sử dụng phương thức `XLSX.utils.aoa_to_sheet([headers, ...rows])` (ma trận 2 chiều) đảm bảo chính xác 100% tất cả dòng và cột theo cấu hình hiển thị thực tế.
3. **Hiển thị Skeleton Loading rõ ràng (Visible Skeleton):**
   - Nhúng CSS Animation Shimmer trực tiếp và thiết lập thời gian hiển thị 700ms mượt mà trước khi load bảng.
4. **Bộ tính năng Table Nâng cao (Toàn bộ yêu cầu từ Feedback 3):**
   - **DOM Native Table:** Bảng HTML chuẩn `<table>/<thead>/<tbody>` hiệu năng cao.
   - **Sticky Header:** Cố định tiêu đề bảng khi cuộn dọc.
   - **Mật độ dòng (Row Density):** 3 mức `compact` (4px 8px), `normal` (8px 12px), `relaxed` (12px 16px).
   - **Kiểu hiển thị (Table Variants):** `striped` (sọc ngựa vằn), `bordered` (viền ô), `default`.
   - **Tùy chỉnh cỡ chữ (Font Size):** Lựa chọn từ 11px đến 15px.
   - **Tự động sinh cột STT:** Có tùy chọn bật/tắt cột Số thứ tự tự động theo trang.
   - **Tự động ngắt dòng (Text Wrap):** Cho phép ngắt dòng hoặc giữ 1 dòng.
   - **Căn lề tự động thông minh:** Căn giữa `STT`/`Date`, căn phải số/tiền tệ/phần trăm, căn trái văn bản.
5. **Sắp xếp tự nhiên (Natural Sort):**
   - Sắp xếp trực tiếp trên Header: Click `<th>` đổi chiều `▲` / `▼` / `↕`.
   - Đa kiểu dữ liệu: Số thực, Ngày tháng, Tiếng Việt chuẩn `Intl.Collator`.
6. **Định dạng Cột (Column Formats) & Màu sắc có điều kiện:**
   - Hỗ trợ đầy đủ: `auto`, `number_comma`, `number_vn` (Tr / Tỷ / K), `currency` (₫), `percent` (%), các kiểu `date`, `badge`, `monospace` (JetBrains Mono).
   - Màu sắc & Badges: `pos_green_neg_red` (dương xanh / âm đỏ), `status_badge` (nhận diện Hoàn thành, Hủy, Chờ...), `green`, `red`, `amber`, `cyan`.
7. **Modal Tùy chỉnh Cột Bảng (Table Column Modal - `⚙️ Cột Bảng`):**
   - Popup lớn trực tiếp trên Dashboard:
     - Ẩn/Hiện cột tùy ý.
     - Đổi tên hiển thị (Label) của cột.
     - Di chuyển thay đổi thứ tự cột lên/xuống.
     - Chọn Format & Màu sắc cho từng cột.
     - Tự động lưu cấu hình riêng của từng người dùng vào `localStorage` (`user_tbl_cols_looker_custom`).
     - Hỗ trợ nút "Khôi phục mặc định" và "Lưu & Áp Dụng".
8. **Đóng gói dự án & Git:**
   - Cập nhật [`customLooker.zip`](file:///D:/customLooker/customLooker.zip).
   - Push lên GitHub [https://github.com/duyvanda/customlooker.git](https://github.com/duyvanda/customlooker.git).
   - Deploy GCS `gs://analytics_merap/excelchart2/`.

## 2. Danh sách file trong gói ZIP & Dự án

- [`src/index.js`](file:///D:/customLooker/src/index.js): Toàn bộ logic Table Viz, Modal Tùy chỉnh cột, LocalStorage, Formatter, Colors, Sort, Pagination & Export.
- [`downloader.html`](file:///D:/customLooker/downloader.html): Giao diện tải file Excel, CSV & Copy JSON.
- [`index.css`](file:///D:/customLooker/index.css): Toàn bộ CSS giao diện Inter font, Modal Popup, Table Variants, Densities, Badges, Mono font & Scrollbar.
- [`index.json`](file:///D:/customLooker/index.json): Khai báo Data Setup (Dimensions, Metrics, SearchFields) và Style Panel (Density, Variant, Font Size, STT, Wrap, Search, Col Config).
- [`manifest.json`](file:///D:/customLooker/manifest.json): Khai báo tài nguyên Community Visualization.
- [`package.json`](file:///D:/customLooker/package.json): Cấu hình dependencies npm.
- [`webpack.config.js`](file:///D:/customLooker/webpack.config.js): Cấu hình đóng gói Webpack.
- [`index.bundle.js`](file:///D:/customLooker/index.bundle.js): File bundle đã build sẵn để deploy (~30.8 KB).
- [`agent.md`](file:///D:/customLooker/agent.md): Tài liệu tổng quan kiến trúc, luồng hoạt động và hướng dẫn sử dụng.
