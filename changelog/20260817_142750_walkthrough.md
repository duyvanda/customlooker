# Walkthrough - Tăng Giới Hạn Cột Dimension Lên 200 & Deploy v3.42

## 1. Mục Đích Thay Đổi
- Tăng giới hạn số lượng cột **Dimension** tối đa có thể kéo vào bảng từ `50` lên `200`.
- Nâng phiên bản lên **v3.42** và deploy trực tiếp lên GCS Production (`gs://analytics_merap/excelchart3/`).
- Dọn dẹp (cleanup) các file phiên bản cũ `v3.41` trên Google Cloud Storage.

## 2. Chi Tiết Thay Đổi
- **File Schema:** `index.json` & `index.v3.42.json`
  - Cập nhật thuộc tính `options.max` trong slot `dimensions`:
    ```json
    {
        "id": "dimensions",
        "label": "Dimension",
        "type": "DIMENSION",
        "options": {
            "min": 0,
            "max": 200
        }
    }
    ```
- **Webpack & Manifest:**
  - `webpack.config.js`: `filename` đổi thành `index.bundle.v3.42.js`.
  - `manifest.json`: cập nhật đường dẫn `js`, `css`, `config` sang `v3.42`.
- **Dọn dẹp & Đóng gói:**
  - Di chuyển các file bundle cũ (`v3.41`) vào thư mục `archive/`.
  - Đóng gói `customLooker.zip`.

## 3. Triển Khai & Cleanup GCS
- **Deploy v3.42:** Đã deploy thành công 6 files lên GCS `gs://analytics_merap/excelchart3/`:
  - `index.bundle.v3.42.js`
  - `index.v3.42.css`
  - `index.v3.42.json`
  - `downloader.html`
  - `index.json`
  - `manifest.json`
- **Cleanup v3.41 trên GCS:** Đã xóa sạch 3 files bản cũ:
  - `gs://analytics_merap/excelchart3/index.bundle.v3.41.js`
  - `gs://analytics_merap/excelchart3/index.v3.41.css`
  - `gs://analytics_merap/excelchart3/index.v3.41.json`
- **Áp dụng:** 0 giây (Bust cache CDN tức thì do URL phiên bản mới hoàn toàn).
