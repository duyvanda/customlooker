# 📋 Walkthrough Nhật Ký Thay Đổi & Deploy (15/08/2026 02:00:20)

## 1. 🎯 Mục Tiêu Yêu Cầu
- Tắt chế độ gỡ lỗi / phát triển (`devMode = false` hay `debug = false`) cho Custom Looker Studio Visualization.
- Build lại gói bundle JS và đóng gói file zip.
- Triển khai (Deploy) toàn bộ tài nguyên lên Google Cloud Storage (GCS) `gs://analytics_merap/excelchart2/`.
- Đồng bộ mã nguồn lên Git repository.

---

## 2. 🛠️ Chi Tiết Các Thay Đổi

### 2.1. Cấu hình Manifest ([`manifest.json`](file:///D:/customLooker/manifest.json))
- Chuyển trường `"devMode": true` sang `"devMode": false` để Looker Studio chuyển sang chế độ Production tối ưu tải và vận hành.

### 2.2. Mã nguồn JS ([`src/index.js`](file:///D:/customLooker/src/index.js))
- Sửa lỗi tham chiếu biến `tableState.currentPage` thành `runtimeState.currentPage` ở nút chuyển về trang cuối (`lastPageBtn`).

### 2.3. Tài liệu kiến trúc ([`agent.md`](file:///D:/customLooker/agent.md))
- Cập nhật trạng thái `manifest.json` (`devMode: false`).
- Chuẩn hóa danh sách file đóng gói trong lệnh `Compress-Archive`.

---

## 3. 🚀 Quy Trình Build & Deploy Đã Thực Hiện

1. **Webpack Build:**
   ```powershell
   npm run build
   ```
   - Tạo ra [`index.bundle.js`](file:///D:/customLooker/index.bundle.js) (~30.6 KB tối ưu).

2. **Nén ZIP:**
   ```powershell
   Compress-Archive -Path "src", "downloader.html", "index.css", "index.json", "manifest.json", "package.json", "webpack.config.js", "index.bundle.js", "agent.md", "feedback.md", "changelog" -DestinationPath "D:\customLooker\customLooker.zip" -Force
   ```
   - Cập nhật gói [`customLooker.zip`](file:///D:/customLooker/customLooker.zip).

3. **Deploy GCS Bucket:**
   ```powershell
   gsutil -h "Cache-Control:no-cache, no-store, must-revalidate" -m cp -a public-read "index.bundle.js" "index.css" "downloader.html" "index.json" "manifest.json" gs://analytics_merap/excelchart2/
   ```
   - Toàn bộ 5 file thành phần đã được đồng bộ lên `gs://analytics_merap/excelchart2/`.

4. **Git Commit & Push:**
   - Commit tiếng Việt và đồng bộ lên branch `main`.
